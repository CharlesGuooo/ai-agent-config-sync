## 一、三条铁律

1. **大白话节（`plain`）每次交付必带**——不论出不出 PDF、不论看几个专题。
   不出 PDF 时，它是聊天回答的最后一节；出 PDF 时，它是封面之后的第一节，**并在聊天里再给一份完整的**。
2. **样式只能来自 `report.css`**。
3. **一律第三人称称呼盘的主人**——见下。

### 称呼约定

**来问的人不一定是盘的主人**，可能在给孩子、伴侣、父母、朋友看。通篇用「你」在这些场合是直接说错人。

```
命主（或用户给的称呼）  = 盘的主人   → 第三人称，用于一切关于此人命运的陈述
你 / 您                = 读报告的人 → 只允许出现在 .ask / .nb / .q 里
```

判断口诀：**这句话是在说「这个人怎么样」，还是在对「读报告的人」提要求？**
前者用命主，后者才可以用你。

这个区分不是新发明的，**原文自己就分了这两个角色**：

| 原文用词 | 指谁 | 出处 |
|---|---|---|
| **命主** | 盘的主人 | ch5「违背原局或者说**命主本人**」· ch22「表**命主**做功的方向」· ch7 校准「说给**命主**对」 |
| **客户** | 来问的人 | ch39「**客户**不问不说」——这条执业规矩管的是**问事人问没问**，不是命主 |

**补充规则**

- 默认用「**命主**」。用户主动给了称呼（姓名／昵称）就用称呼，**一旦选定全篇统一**。
- 需要代词时按脚本给出的性别用「他／她」，**不要用「TA」混排**；也不要连续重复「命主」造成累赘——
  改成无主语的句子往往更自然（`建议你主动求变` → `这一年宜主动求变`）。
- 涉及六亲写「**命主的**父亲／配偶／子女」，不写「你爸／你老婆」。
- **这条对聊天直接解读同样生效**，不只管 PDF。

**为什么 `.q` 也在白名单里**：引文里的「你」是《金口诀》作者在对他的学生说话，不是本报告在称呼读者；
且 `SKILL.md` 输出纪律第 1 条规定「断语照原文措辞，不改写、不软化」——**lint 不能逼着去篡改原文**。

### 分工纪律

| 谁 | 负责 |
|---|---|
| Claude | 只写节内容片段 `sections/<id>.html` —— **纯 body 片段**，只用下面登记的 CSS 类 |
| `build_pdf.py` | doctype · `<meta charset>` · `<title>` · CSS 注入 · 节次排序 · 分页 · 验收 |

片段里出现 `<style>`、`style="`、`<html>`、`<body>`、`<head>`、`<link>`、`<script>` —— **脚本报错退出**。
这条不是建议，是 lint。

## 三、大白话节规格

写给**完全不懂命理的人**。他读完应该知道三件事：我是个什么结构、我该注意什么、哪些年份要留心。

### 结构：固定骨架 ＋ 按选中专题伸缩

| 段 | 内容 | 出现条件 | 篇幅 |
|---|---|---|---|
| 1 | **这盘最核心的一件事** —— 用一个生活比喻讲清结构（谁本该管你、谁在中间和稀泥） | 固定 | 200–300 字 |
| 2 | **命主手里有什么、没有什么** —— 工具与资源盘点 | 固定 | 150–250 字 |
| 3 | **每个选中专题一段** | 每专题一段 | 150–400 字／段 |
| 4 | **怎么认好年坏年** —— 给可自查的口诀 | 固定 | ~200 字 |
| 5 | **近几年** | 固定 | ~200 字 |
| 6 | **我需要你确认的** | 有校验点时 | 列表 |

**总长**：单专题 800–1200 字；全批 2000–2500 字。脚本在 <500 字时告警。

### 硬规格

- **零术语**。除 22 个干支字、以及「天干／地支」（讲自查规则时要用）之外，
  不出现任何命理专名。确需表达时**换成生活语言**——写「命里带的一把刀」，不写「羊刃」。
- 每段落到**一个可执行的点**，不止描述。
- 口径用「倾向／偏向／需要留意」，不用「一定／必然」。
- **不重复术语章节的推导**，只给结论与含义。
- 段 4 要给能自己查的规则，例如：
  > 好年 —— 天干见「丙」「丁」，地支见「午」「寅」
  > 难年 —— 天干见「癸」，地支见「卯」「酉」

### 禁入词表（脚本硬检查，命中即失败）

```
做功 体用 宫星 主宾 取象 类象 金口诀 成格之字 败格之字 判据 反局 限运
大运 流年 十神 比肩 劫财 食神 伤官 正财 偏财 正官 七杀 正印 偏印
羊刃 阳刃 阴刃 墓库 空亡 驿马 禄神 官符 亡神 通关 日主 藏干 纳音
长生 帝旺 断语 应期 清纯 党势 意向 元神      以及 ch\d+
```

正本在 `build_pdf.py` 的 `PLAIN_BANNED`。**「大运／流年」也在表内**——用「这十年」「那一年」代替。

## 四、可用 CSS 类清单

片段里只能用这些。想要别的效果，改 `report.css` 并在此登记，不要 inline。

| 类 | 用途 |
|---|---|
| `h2` `h3` `h4` `p` `ul` `ol` `li` `table` `thead` `th` `td` `code` `pre` | 标准元素，已配好打印样式 |
| `.c` | 单元格居中（`<td class="c">`） |
| `.q` ＋ `.src` | 金口诀引文（楷体块）＋ 出处标记 |
| `.box` `.box.warn` `.box.good` `.box.key` ＋ `.lbl` | 面板（中性／警示／利好／要点）＋ 面板小标签 |
| `.ji` `.xiong` `.zh` | 语义色：吉（竹绿）／凶（朱砂）／中性 |
| `.cf` `.cf.h` `.cf.m` `.cf.l` | 置信度标签：高／中／低 |
| `.pillars` ＋ `td.big` `td.big.hi` `td.rk` | 四柱盘面表（大字／高亮／行首标签） |
| `.cover` ＋ `.t1` `.t2` `.rule` `.gz` `.meta` `.oneline` `.foot` | 封面专用 |
| `.plain` ＋ `.plain .hi` `.plain .ask` | **大白话节专用**：大字号松行距／高亮句／待确认块 |
| **`.ask` `.nb` `.q`** | **第二人称白名单**——只有这三类块里可以出现「你／您」（分别是：对读者提要求／阅读引导／原文引文）。正文别处需要对读报告的人说话时，**包进 `.nb`** |
| `.tl` ＋ `.ev` `.ev.r` `.ev.g` `.yr` | 时间轴（人生分段走势）：中性／凶／吉 |
| `.two > div` | 并排两栏 |
| `.nb` | 小字注 |
| `.disclaimer` ＋ `.t` | 免责声明块 |
| **`.pb`** | **主动断页**（`break-before: page`）。验收报「近空页」时用它把长节切匀，加在 `h3`/`h4` 上最自然 |
| **`.keep`** | **不与上文分离**（`break-inside`＋`break-before: avoid`）。包住「一组框＋收尾一句」，防止收尾句被孤立到新页 |

> `.sec` 由脚本自动包裹，**片段里不要写**。

### 遇到「近空页」怎么修

验收失败时脚本会指出是第几页。两种成因、两种修法：

| 成因 | 现象 | 修法 |
|---|---|---|
| 节太长，末尾一小段溢出 | 该页只有一两段文字 | 在该节中部某个 `h3`/`h4` 上加 `class="pb"`，把内容切成两页均匀分布 |
| 一组框／一行表格被挤下去 | 该页只有孤零零一个块 | 用 `<div class="keep">` 把这组内容和它的收尾句包在一起，让它们整体移动 |

阈值两级：**<80 字符＝失败**（几乎空白）；**80–200 字符＝告警**（偏薄，可接受但加 `.pb` 更好看）。

## 五、构建与验收

```bash
python output/build_pdf.py --sections <片段目录> --out <输出.pdf> [--title "..."]
python output/build_pdf.py --sections <片段目录> --lint-only      # 只查片段
python output/build_pdf.py --list-sections                        # 打印节次目录
```

**渲染器**三级回退，零安装：Playwright headless shell → Chrome → Edge。
参数固定 `--headless --disable-gpu --no-sandbox --user-data-dir=<临时> --no-pdf-header-footer --virtual-time-budget=8000`。
用临时 profile 是为了**不附着到用户正在开的浏览器会话**。

### 自动验收（每次生成后跑，失败退出码 2）

| 项 | 标准 |
|---|---|
| 幅面 | A4，595×842pt（容差 3pt） |
| **豆腐块／替换字符** | **必须为 0**——非 0 说明字体缺字形 |
| 近空页 | 第 2 页起：**<80 字符＝失败**；80–200 字符＝告警（可接受，加 `.pb` 更好看） |
| 免责声明 | 必须在末页（或倒数第二页） |
| 大白话节位置 | 必须落在前 25% 的页里 |
| 大白话节术语 | 禁入词命中数为 0 |
| **人称** | **白名单（`.ask` / `.nb` / `.q`）之外不得出现「你／您」**——见 §一 称呼约定 |

肉眼验收（脚本不做，人做）：用 `pypdfium2` 把封面、大白话节、一个专题节渲染成 PNG 看一眼。

```
盲派详批_<生日>_<四柱>[_<专题>].pdf
```

| 情形 | 文件名 |
|---|---|
| 全批 | `盲派详批_<生日>_<四柱>.pdf` |
