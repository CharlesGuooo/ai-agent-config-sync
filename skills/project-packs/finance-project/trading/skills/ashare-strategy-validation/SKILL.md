# A 股策略验证

一条从书里抄来的规则，在被测过之前**既不是知识也不是噪声，它只是一句话**。
这个 skill 把它变成能判死活的东西。

**统计方法不在这里。** PBO、Deflated Sharpe、White's Reality Check、时序交叉验证、
仓位公式已经在 finance-project 的 quant-methods 包里了（各 skill 在 `<pack>/.claude/skills/` 下，
见下方委派表），而且比重写一遍好。
这里只装**那些库不知道的 A 股事实**，以及一本墓地。

**项目需提供的文件**（相对使用者 A 股项目的根目录）：规格书 `信号层判据规格.md`（§2 字段、§15 检验协议）；
`AGENT.md`（项目约定，下文引用其 O2、O9 条）；`候选假设集.md`（先验假设清单）；
以及项目数据目录里的市场层宽表 `regime_history` 与个股日线数据。

## 第 0 步 · 先算样本量，再动手

**这一步在最前面，因为它经常直接终止后面的工作。**

平台的市场层数据是 `regime_history`，**244 行**。实测阶段分布：

| phase | 天数 |
|---|---:|
| `repair` | 207（84.8%） |
| `ignite` | 14 |
| `rally` | 13 |
| `ebb` | 7 |
| `ice` | 3 |
| `climax` | **0** |

`MIN_BASELINE_SAMPLES = 12`。所以：

- 非修复日全年约 **37 天**
- `ebb`(7)、`ice`(3) **永远拿不到基准率**
- **`climax` 一次都没出现过** —— 任何针对高潮期的假设标 `待数据`，**不是 `未通过`**

> **一条 5% 命中率的市场级规则，一年只有约 12 个事件。** 在这个样本上「验证」出来的任何结论，
> 都是在测噪声。

### 解法：改到个股-日截面上测

同样一条规则，在**个股-日**上有数千个事件（244 个交易日 × 数千只标的）。
样本地板自然消失。

- **市场级假设**（关于 `phase`、`limit_up`、`promo_rate` 等）→ 样本受限于 244 行，多数不可测
- **个股级假设**（关于形态、量价、均线）→ 在截面上测，样本充足

**默认走截面。** 只有当假设的对象本身就是市场状态时才走时序，且必须先报样本量。

**完成判据**：写下了事件数的**具体数字**（截面或时序），以及它与门槛（截面 ≥ 数百 / 时序 ≥ 12）
的比较结论。**没有数字就是没算**——「样本应该够」不是完成。

## 判定是否可测

按顺序问，任何一条为「否」就停在那里，标好状态：

| 检查 | 否 → 标记 |
|---|---|
| 依赖的字段平台有吗？（查规格书 §2） | `待数据` + 缺口编号 |
| 事件数够吗？（截面 ≥ 数百，时序 ≥ 12） | `待数据` + 实际事件数 |
| 涉及板块/题材成员吗？ | **`不可回测`**，见下 |
| 入场价在 A 股能成交吗？ | `不可执行`，见 `references/A股约束.md` |

### `不可回测`：板块成员的前视污染

同花顺概念/行业成分表**只有当前快照，没有历史版本**。任何「当时这只票属于 X 板块」的陈述
都是今天的知识倒灌回去的。

**污染的方向恰好使你倾向于采纳该规则**——今天还在这个概念里的票，往往正是当初涨得好的那些。
这不是随机噪声，是系统性偏向。

**所以这是硬标记，不是「注意一下」。** 涉及板块成员的假设一律标 `不可回测`，
直到有 PIT 版本的成分表。

## 规格模板

把一条经验法则写成规格，模板见 `references/规格模板.md`。必填项：

标的池 · 入场（可编码，含触发时点）· 离场 · 止损 · 最长持有期 · 成本模型 ·
**零假设** · **无条件基准的定义** · 最小样本 · **预登记终止日期**

**预登记终止日期**是防过拟合的主要装置：在看数据之前写下「测到什么日期为止、
达不到什么标准就判死」。写完才能开始跑。

## 基准率检验协议

`edge` 的定义是「命中 − 基准率」，所以**基准率怎么算决定了一切**。协议在规格书 §15，
要点三条：

1. **建立无条件基线**：同标的池、同窗口上跑「每天都买、持有 H 日平」，记下准确率与单笔均利。
   **必须做漂移校正**——威廉斯的原话是「52% 而不是 50%，因为样本期整体上涨」。A 股同理，
   **50% 不是正确的零假设**。
2. **两个数一起看**：加了条件之后，准确率**和**单笔均利必须同时超过基线。
3. **过滤器的形状**：每加一层条件，事件数应保持在三位数以上，且准确率与单笔均利**同向抬升**。

### 两条对威廉斯本人的修正

- **不要抄他的样本量。** 他实际低到 25–28 笔就敢发表结论，并在 N=41 时写下「没有比这个结果更好的了」。
  这是他方法论里最脆弱的地方。
- **他把两个检验合并了，必须拆开。** 第二版重测显示同一形态在两个时代都「统计显著」，
  但**单笔均利腰斩**（$134→$87、$212→$79，准确率却持平甚至上升），他对此未作评论。
  → **「是否非随机」和「是否还值得交易」是两个不同的问题，分别出结论。**

## 结算：写进墓地

每条被判死的假设进 `references/已知失效.md`，带日期、ID、判死理由与当时的事件数。

**重新提议一条已在墓地里的假设时，必须先说明这次为什么不同。** 这是让系统不再反复重提
`启动 → ge2_count 上升`（实测 0–1/11–13，各时间跨度都不成立）的唯一机制。

## 一条硬约束：不要拟合 `PHASE_EXPECTATIONS`

`AGENT.md` O9 明写：

> **Do not tune `PHASE_EXPECTATIONS` to fit the past year** —— that is the overfitting the
> scoreboard exists to catch.

所以候选假设的**出处必须是先验，不是回测扫参**。项目里 `候选假设集.md` 的假设
全部来自 2025-12 的实操文本——先声明、后检验，这是防过拟合的正解，不是绕过它的借口。
