# Harness v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use `subagent-driven-development` (recommended) or
> `executing-plans` to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 用一个零依赖的 Node 安装器取代 v1 的复制式同步：skill 用链接，配置按条目合并，冲突三方比较，支持 Windows/macOS/Linux 和任意几个 agent。

**Architecture:** 设计见 `docs/harness-v2.md`。`harness.mjs` 是命令行入口；`lib/` 下每个模块管一种受管对象（链接、文本块、JSON 条目、TOML 表）；`lib/agents/*.mjs` 是五个 agent 的适配器，只描述"东西放哪、用什么格式"；`lib/engine.mjs` 把它们串起来，所有写入都经过 `lib/decide.mjs` 的同一条三方比较规则。

**Tech Stack:** Node 20+（ESM，`.mjs`，只用内置模块），测试用 `node:test`（跑全部测试需要 Node 22+，因为要用 `--test` 的 glob）。

```js
// Small file and value helpers shared by the installer modules.
import { readFileSync, writeFileSync, mkdirSync, existsSync } from 'node:fs';
import { dirname } from 'node:path';
import { createHash } from 'node:crypto';

export const lf = (text) => text.replace(/\r\n/g, '\n');

export function readText(p) {
  return existsSync(p) ? readFileSync(p, 'utf8').replace(/^\uFEFF/, '') : null;
}

export function writeText(p, text) {
  mkdirSync(dirname(p), { recursive: true });
  writeFileSync(p, text);
}

export function readJson(p) {
  const text = readText(p);
  return text === null ? null : JSON.parse(text);
}

export function writeJson(p, value) {
  writeText(p, `${JSON.stringify(value, null, 2)}\n`);
}

export const isObj = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);

// JSON with object keys sorted at every level, so equal values serialize equally.
export function canon(v) {
  return JSON.stringify(v, (_k, x) => (isObj(x) ? Object.fromEntries(Object.keys(x).sort().map((k) => [k, x[k]])) : x));
}

const sha = (s) => createHash('sha256').update(s).digest('hex').slice(0, 16);

// Hash of a JSON-like value; null when the value is absent.
export const hashValue = (v) => (v === undefined ? null : sha(canon(v)));

// Hash of text with line endings normalized; null when the text is absent.
export const hashText = (t) => (t === null || t === undefined ? null : sha(lf(t)));

export const getPath = (obj, path) => path.reduce((o, k) => (isObj(o) ? o[k] : undefined), obj);

export function setPath(obj, path, value) {
  let o = obj;
  for (const k of path.slice(0, -1)) o = isObj(o[k]) ? o[k] : (o[k] = {});
  o[path[path.length - 1]] = value;
}

export function deletePath(obj, path) {
  const parent = getPath(obj, path.slice(0, -1));
  if (isObj(parent)) delete parent[path[path.length - 1]];
}
```

```js
// OS detection, the run context, and directory links. Links are junctions on
// Windows (no admin or Developer Mode needed) and symlinks elsewhere; which kind
// is decided by the host, while ctx.os decides how configs are rendered.
import { symlinkSync, readlinkSync, lstatSync, rmdirSync, unlinkSync, rmSync, mkdirSync, statSync } from 'node:fs';
import { dirname, resolve, join, sep } from 'node:path';
import { homedir, platform } from 'node:os';

const HOST_WIN = process.platform === 'win32';

export function osName(p = platform()) {
  return p === 'win32' ? 'windows' : p === 'darwin' ? 'mac' : 'linux';
}

// repo = this checkout; home = whose agents get configured; local = where the
// machine state and generated Cursor rules live (default <repo>/.local).
export function makeContext({ repo, home, os = osName(), local }) {
  return { repo: resolve(repo), home: resolve(home ?? homedir()), os, local: resolve(local ?? join(repo, '.local')) };
}

// Forward-slash form of a path, for generated configs and hook commands.
export const slash = (p) => p.replace(/\\/g, '/');

const norm = (p) => (HOST_WIN ? resolve(p).toLowerCase() : resolve(p));

export const samePath = (a, b) => norm(a) === norm(b);

export const inside = (root, p) => norm(p).startsWith(norm(root) + sep);

export function isLink(p) {
  try {
    return lstatSync(p).isSymbolicLink();
  } catch {
    return false;
  }
}

export function linkTarget(p) {
  return isLink(p) ? resolve(dirname(p), readlinkSync(p)) : null;
}

export function makeDirLink(target, linkPath) {
  mkdirSync(dirname(linkPath), { recursive: true });
  symlinkSync(target, linkPath, HOST_WIN ? 'junction' : 'dir');
}

// Removes the link itself; what it points to is never touched.
export function removeLink(p) {
  if (HOST_WIN) rmdirSync(p);
  else unlinkSync(p);
}

// Removes a real file or directory tree. Refuses a link, so a tree delete can
// never start walking into the repo through a junction.
export function removeTree(p) {
  if (isLink(p)) throw new Error(`refusing to tree-delete a link: ${p}`);
  rmSync(p, { recursive: true, force: true });
}

// True for a linked git worktree (its .git is a file), false for the main checkout.
export function isWorktree(repo) {
  try {
    return statSync(join(repo, '.git')).isFile();
  } catch {
    return false;
  }
}
```

`lib/decide.mjs`:

```js
// The one rule every managed item follows. current = what the machine has now,
// desired = what the repo wants, last = what this installer wrote the previous
// time (written = there was a previous time). Values are hashes; null = absent.
// Returns 'ok' (nothing to do), 'write', 'skip' (pinned or kept) or 'conflict'.
export function decide({ current, desired, last, written, pinned, resolution }) {
  if (resolution === 'repo') return current === desired ? 'ok' : 'write';
  if (pinned) return 'skip';
  if (current === desired) return 'ok';
  if (resolution === 'keep') return 'skip';
  if (!written) return current === null ? 'write' : 'conflict';
  return current === last ? 'write' : 'conflict';
}
```

`lib/run.mjs`:

```js
// One install/update pass: the machine state, the resolutions given on the
// command line, and the report. step() applies decide() to one managed item and
// records the outcome in the state.
import { decide } from './decide.mjs';

export function makeRun({ state, resolutions = {}, dryRun = false }) {
  const report = { changes: [], conflicts: [], warnings: [], notes: [] };
  const run = {
    state,
    report,
    dryRun,
    agent: null,
    seen: new Set(),
    resolution: (id) => resolutions[id] ?? resolutions.all,
    change: (msg) => report.changes.push(msg),
    warn: (msg) => report.warnings.push(msg),
    note: (msg) => report.notes.push(msg),
    conflict: (id, msg) => report.conflicts.push({ id, msg }),
    // True when the caller should write `desired` (or remove, when desired is null).
    step(id, meta, current, desired, label) {
      run.seen.add(id);
      const entry = state.entries[id];
      const resolution = run.resolution(id);
      const verdict = decide({ current, desired, last: entry?.hash ?? null, written: Boolean(entry), pinned: Boolean(entry?.pinned), resolution });
      if (verdict === 'conflict') {
        run.conflict(id, label);
        return false;
      }
      if (verdict === 'skip') {
        if (resolution === 'keep' && !entry?.pinned) {
          state.entries[id] = { agent: run.agent, ...meta, hash: entry?.hash ?? null, pinned: true };
          run.note(`kept this machine's version and stopped managing it: ${id}`);
        }
        return false;
```

```js
// One link per repo skill inside an agent's skill directory. Links that point
// into the repo at skills it no longer has are removed; everything else in the
// directory (vendor skills, ones you installed yourself) is never touched.
import { readdirSync, readFileSync, existsSync } from 'node:fs';
import { join } from 'node:path';
import { isLink, linkTarget, makeDirLink, removeLink, removeTree, samePath, inside } from './platform.mjs';

export function syncLinks(ctx, { src, names, dst }, run) {
  for (const name of names) linkOne(ctx, join(src, name), join(dst, name), run);
  pruneLinks(ctx, dst, (name, target) => names.includes(name) && samePath(target, join(src, name)), run);
}

function act(run, label, fn) {
  run.change(label);
  if (!run.dryRun) fn();
}

function linkOne(ctx, target, path, run) {
  const id = `link:${path}`;
  if (isLink(path)) {
    const current = linkTarget(path);
    if (samePath(current, target)) return;
    if (!inside(ctx.repo, current)) return run.conflict(id, `links somewhere outside the repo (${current}): ${path}`);
    return act(run, `relink ${path}`, () => {
      removeLink(path);
      makeDirLink(target, path);
    });
  }
  if (existsSync(path)) {
    // A real directory: a copy left by the v1 sync, or something you put there.
    const resolution = run.resolution(id);
    if (resolution === 'keep') return;
    if (resolution !== 'repo' && !dirsEqual(path, target)) return run.conflict(id, `a real directory here differs from the repo's copy: ${path}`);
    return act(run, `replace-copy ${path}`, () => {
      removeTree(path);
      makeDirLink(target, path);
    });
  }
  act(run, `link ${path}`, () => makeDirLink(target, path));
}

// Removes links in `dir` that point into the repo, unless keep(name, target)
// says otherwise and the target still exists.
export function pruneLinks(ctx, dir, keep, run) {
  if (!existsSync(dir)) return;
  for (const name of readdirSync(dir)) {
    const path = join(dir, name);
    const target = linkTarget(path);
    if (!target || !inside(ctx.repo, target)) continue;
    if (keep(name, target) && existsSync(target)) continue;
    act(run, `unlink ${path}`, () => removeLink(path));
  }
}

function files(root, rel = '', out = new Map()) {
  for (const e of readdirSync(join(root, rel), { withFileTypes: true })) {
    if (e.name === '__pycache__' || e.name === '.git') continue;
    const r = rel ? `${rel}/${e.name}` : e.name;
    if (e.isDirectory()) files(root, r, out);
    else if (e.isFile()) out.set(r, join(root, r));
  }
  return out;
}

// Same relative file set with the same bytes (Python caches ignored).
export function dirsEqual(a, b) {
  const fa = files(a);
  const fb = files(b);
  if (fa.size !== fb.size) return false;
  for (const [rel, p] of fa) {
    const q = fb.get(rel);
    if (!q || !readFileSync(p).equals(readFileSync(q))) return false;
  }
  return true;
}
```

```js
// Text the repo owns: whole files (commands, templates), and a marked block
// inside a file the machine also owns (agent instruction files). Text outside
// the markers is never touched.
import { existsSync, unlinkSync } from 'node:fs';
import { readText, writeText, hashText, lf } from './util.mjs';

export const BEGIN = '<!-- >>> ai-agent-config-sync (managed: edit the repo, not this block) -->';
export const END = '<!-- <<< ai-agent-config-sync -->';

// The v1 sync wrote whole instruction files with a generated table between these markers.
export const isV1Prompt = (text) => text.includes('<!-- SKILLS:BEGIN -->') && text.includes('<!-- SKILLS:END -->');

export function splitBlock(text) {
  const t = lf(text);
  const i = t.indexOf(BEGIN);
  const j = t.indexOf(END);
  if (i === -1 || j < i) return null;
  return { before: t.slice(0, i), inner: t.slice(i + BEGIN.length, j).replace(/^\n/, '').replace(/\n$/, ''), after: t.slice(j + END.length) };
}

const block = (content) => `${BEGIN}\n${content}\n${END}`;

export function applyBlock({ id, file, content }, run) {
  const text = readText(file);
  const parts = text === null ? null : splitBlock(text);
  const meta = { kind: 'block', file };
  if (parts) {
    if (run.step(id, meta, hashText(parts.inner), hashText(content), `update ${file}`) && !run.dryRun) {
      writeText(file, parts.before + block(content) + parts.after);
    }
    return;
  }
  if (!run.step(id, meta, null, hashText(content), `write ${file}`) || run.dryRun) return;
  // No block yet: a v1 file is replaced whole; anything else stays, below the block.
  writeText(file, text === null || isV1Prompt(text) ? `${block(content)}\n` : `${block(content)}\n\n${lf(text)}`);
}

export function removeBlock({ id, file }, run) {
  const text = readText(file);
  const parts = text === null ? null : splitBlock(text);
  if (!run.step(id, { kind: 'block', file }, parts ? hashText(parts.inner) : null, null, `remove-block ${file}`) || !parts || run.dryRun) return;
  const rest = (parts.before + parts.after).replace(/^\n+/, '');
  if (rest.trim() === '') unlinkSync(file);
  else writeText(file, rest);
}

export function applyFile({ id, file, content }, run) {
  if (run.step(id, { kind: 'file', file }, hashText(readText(file)), hashText(content), `write ${file}`) && !run.dryRun) {
    writeText(file, content);
  }
}

export function removeFile({ id, file }, run) {
  if (run.step(id, { kind: 'file', file }, hashText(readText(file)), null, `remove ${file}`) && !run.dryRun && existsSync(file)) {
    unlinkSync(file);
  }
}
```

```js
// Repo-owned entries in JSON config files that the agent itself also writes.
// An entry is one key path (["mcpServers", "github"]); a hook is a group in
// hooks.<Event>, found by the command it runs. Everything else is left alone.
import { readText, writeJson, hashValue, getPath, setPath, deletePath, isObj } from './util.mjs';

function load(file) {
  const text = readText(file);
  return text === null || text.trim() === '' ? {} : JSON.parse(text);
}

const group = (h) => ({ matcher: h.matcher, hooks: [{ type: 'command', command: h.command }] });

function findGroup(obj, event, commands) {
  const groups = isObj(obj.hooks) && Array.isArray(obj.hooks[event]) ? obj.hooks[event] : [];
  return { groups, index: groups.findIndex((g) => (g.hooks ?? []).some((x) => commands.includes(x.command))) };
}

// entries: [{ id, path, value }] or [{ id, skip: true }]; hooks: [{ id, event, matcher, command }].
export function applyJson({ file, entries = [], hooks = [] }, run) {
  const obj = load(file);
  let dirty = false;
  for (const e of entries) {
    if (e.skip) {
      run.seen.add(e.id);
      continue;
    }
    if (run.step(e.id, { kind: 'json', file, path: e.path }, hashValue(getPath(obj, e.path)), hashValue(e.value), `set ${e.path.join('.')} in ${file}`)) {
      setPath(obj, e.path, e.value);
      dirty = true;
    }
  }
  for (const h of hooks) {
    // The command we wrote last time finds our group even after the repo moved.
    const last = run.state.entries[h.id]?.command;
    const { groups, index } = findGroup(obj, h.event, [h.command, last].filter(Boolean));
    const meta = { kind: 'hook', file, event: h.event, command: h.command };
    if (run.step(h.id, meta, index === -1 ? null : hashValue(groups[index]), hashValue(group(h)), `hook ${h.event} ${h.command} in ${file}`)) {
      if (!isObj(obj.hooks)) obj.hooks = {};
      obj.hooks[h.event] = groups;
      if (index === -1) groups.push(group(h));
      else groups[index] = group(h);
      dirty = true;
    }
  }
  if (dirty && !run.dryRun) writeJson(file, obj);
}

// Removes entries and hooks written earlier; items are state entries with their id.
export function removeJson(file, items, run) {
  const obj = load(file);
  let dirty = false;
  for (const it of items) {
    if (it.kind === 'json') {
      if (run.step(it.id, { kind: 'json', file, path: it.path }, hashValue(getPath(obj, it.path)), null, `remove ${it.path.join('.')} from ${file}`)) {
        deletePath(obj, it.path);
        dirty = true;
      }
      continue;
    }
    const { groups, index } = findGroup(obj, it.event, [it.command]);
    const meta = { kind: 'hook', file, event: it.event, command: it.command };
    if (run.step(it.id, meta, index === -1 ? null : hashValue(groups[index]), null, `remove-hook ${it.event} ${it.command} from ${file}`) && index !== -1) {
      groups.splice(index, 1);
      dirty = true;
    }
  }
  if (dirty && !run.dryRun) writeJson(file, obj);
}
```

```js
// Just enough TOML for Codex's config.toml: split the file into tables by
// header, read the [mcp_servers.<name>] tables this repo owns, and rewrite only
// those. Codex re-serializes the file itself (sorts tables, drops comments,
// writes 30 as 30.0), so ownership checks compare parsed values, never text.
import { readText, writeText, hashValue, isObj, setPath, lf } from './util.mjs';

// "a.'b c'.\"d\"" -> ['a', 'b c', 'd']
export function parseKey(s) {
  const out = [];
  let i = 0;
  const space = () => {
    while (s[i] === ' ' || s[i] === '\t') i++;
  };
  while (i < s.length) {
    space();
    if (s[i] === '"') {
      let v = '';
      for (i++; i < s.length && s[i] !== '"'; i++) v += s[i] === '\\' ? s[++i] : s[i];
      out.push(v);
      i++;
    } else if (s[i] === "'") {
      const j = s.indexOf("'", i + 1);
      if (j === -1) throw new Error(`bad TOML key: ${s}`);
      out.push(s.slice(i + 1, j));
      i = j + 1;
    } else {
      const m = /^[A-Za-z0-9_-]+/.exec(s.slice(i));
      if (!m) throw new Error(`bad TOML key: ${s}`);
      out.push(m[0]);
      i += m[0].length;
    }
    space();
    if (s[i] === '.') i++;
  }
  return out;
}

// Tracks strings and brackets across lines, so the "[" that opens a continuation
// line inside a multi-line array is never taken for a table header.
function scan(line, st) {
  let i = 0;
  while (i < line.length) {
    if (st.multi) {
      const j = line.indexOf(st.multi, i);
      if (j === -1) return;
      i = j + 3;
      st.multi = null;
      continue;
    }
    const c = line[i];
    if (c === '#') return;
    if (line.startsWith('"""', i) || line.startsWith("'''", i)) {
      st.multi = line.slice(i, i + 3);
      i += 3;
      continue;
    }
    if (c === '"') {
      for (i++; i < line.length && line[i] !== '"'; i += line[i] === '\\' ? 2 : 1);
      i++;
      continue;
    }
    if (c === "'") {
      const j = line.indexOf("'", i + 1);
      i = j === -1 ? line.length : j + 1;
      continue;
    }
    if (c === '[') st.depth++;
    else if (c === ']') st.depth = Math.max(0, st.depth - 1);
    i++;
  }
}

const HEADER = /^\s*(\[\[?)\s*(.+?)\s*\]\]?\s*(?:#.*)?$/;

// The file as a list of tables { header, path, array, lines }; the first entry
// (header null) holds the lines before any table. joinSegments() restores the text.
export function segments(text) {
  const segs = [{ header: null, path: [], array: false, lines: [] }];
  const st = { multi: null, depth: 0 };
  for (const line of lf(text).split('\n')) {
    const m = !st.multi && st.depth === 0 ? HEADER.exec(line) : null;
    if (m) {
      segs.push({ header: line, path: parseKey(m[2]), array: m[1] === '[[', lines: [] });
      continue;
    }
    segs[segs.length - 1].lines.push(line);
    scan(line, st);
  }
  return segs;
}

export const joinSegments = (segs) => segs.flatMap((s) => (s.header === null ? s.lines : [s.header, ...s.lines])).join('\n');

function unescape(s) {
  const map = { n: '\n', t: '\t', r: '\r', b: '\b', f: '\f', '"': '"', '\\': '\\' };
  return s.replace(/\\(u[0-9a-fA-F]{4}|U[0-9a-fA-F]{8}|.)/g, (_, e) => (e.length > 1 ? String.fromCodePoint(parseInt(e.slice(1), 16)) : map[e] ?? e));
}

// key = value lines: strings, numbers, booleans, arrays and inline tables.
export function parseBody(text) {
  let i = 0;
  const out = {};
  const fail = () => {
    throw new Error(`unsupported TOML near: ${text.slice(i, i + 40)}`);
  };
  const skip = (newlines) => {
    for (;;) {
      while (i < text.length && (text[i] === ' ' || text[i] === '\t' || text[i] === '\r' || (newlines && text[i] === '\n'))) i++;
      if (text[i] !== '#') return;
      while (i < text.length && text[i] !== '\n') i++;
    }
  };
  const pair = (obj) => {
    const eq = text.indexOf('=', i);
    if (eq === -1) fail();
    const key = parseKey(text.slice(i, eq).trim());
    i = eq + 1;
    setPath(obj, key, value());
  };
  const value = () => {
    skip(true);
    if (text.startsWith('"""', i) || text.startsWith("'''", i)) {
      const q = text.slice(i, i + 3);
      const j = text.indexOf(q, i + 3);
      if (j === -1) fail();
      const raw = text.slice(i + 3, j).replace(/^\n/, '');
      i = j + 3;
      return q === '"""' ? unescape(raw) : raw;
    }
    const c = text[i];
    if (c === '"') {
      let j = i + 1;
      while (j < text.length && text[j] !== '"') j += text[j] === '\\' ? 2 : 1;
      if (j >= text.length) fail();
      const s = unescape(text.slice(i + 1, j));
      i = j + 1;
      return s;
    }
    if (c === "'") {
      const j = text.indexOf("'", i + 1);
      if (j === -1) fail();
      const s = text.slice(i + 1, j);
      i = j + 1;
      return s;
    }
    if (c === '[') {
      i++;
      const arr = [];
      for (;;) {
        skip(true);
        if (text[i] === ']') {
          i++;
          return arr;
        }
        if (i >= text.length) fail();
        arr.push(value());
        skip(true);
        if (text[i] === ',') i++;
      }
    }
    if (c === '{') {
      i++;
      const obj = {};
      for (;;) {
        skip(false);
        if (text[i] === '}') {
          i++;
          return obj;
        }
        if (i >= text.length) fail();
        pair(obj);
        skip(false);
        if (text[i] === ',') i++;
      }
    }
    if (text.startsWith('true', i)) {
      i += 4;
      return true;
    }
    if (text.startsWith('false', i)) {
      i += 5;
      return false;
    }
    const m = /^[+-]?\d[\d_]*(?:\.\d[\d_]*)?(?:[eE][+-]?\d+)?/.exec(text.slice(i));
    if (!m) fail();
    i += m[0].length;
    return Number(m[0].replace(/_/g, ''));
  };
  for (;;) {
    skip(true);
    if (i >= text.length) return out;
    pair(out);
  }
}

const ownTable = (s, name) => !s.array && s.path[0] === 'mcp_servers' && s.path[1] === name;

// [mcp_servers.<name>] together with its sub-tables, or undefined.
export function readMcpTable(text, name) {
  let value;
  for (const s of segments(text)) {
    if (!ownTable(s, name)) continue;
    value ??= {};
    const body = parseBody(s.lines.join('\n'));
    if (s.path.length === 2) Object.assign(value, body);
    else setPath(value, s.path.slice(2), body);
  }
  return value;
}

const bare = (k) => (/^[A-Za-z0-9_-]+$/.test(k) ? k : JSON.stringify(k));

function tomlValue(v) {
  if (typeof v === 'string') return JSON.stringify(v);
  if (typeof v === 'number' || typeof v === 'boolean') return String(v);
  if (Array.isArray(v)) return `[${v.map(tomlValue).join(', ')}]`;
  throw new Error(`cannot write TOML value ${JSON.stringify(v)}`);
}

export function renderMcpTable(name, value) {
  const head = `mcp_servers.${bare(name)}`;
  const lines = [`[${head}]`];
  for (const [k, v] of Object.entries(value)) if (!isObj(v)) lines.push(`${bare(k)} = ${tomlValue(v)}`);
  for (const [k, v] of Object.entries(value)) {
    if (!isObj(v)) continue;
    lines.push('', `[${head}.${bare(k)}]`);
    for (const [kk, vv] of Object.entries(v)) lines.push(`${bare(kk)} = ${tomlValue(vv)}`);
  }
  return lines.join('\n');
}

// Replaces the named [mcp_servers.*] tables (undefined removes one); every other
// line of the file stays exactly as it was.
export function writeMcpTables(text, tables) {
  const names = Object.keys(tables);
  const kept = segments(text).filter((s) => !names.some((n) => ownTable(s, n)));
  let out = joinSegments(kept).replace(/\s*$/, '\n');
  for (const [name, value] of Object.entries(tables)) if (value !== undefined) out += `\n${renderMcpTable(name, value)}\n`;
  return out;
}

// Drops [[hooks.<Event>]] groups, with their [[hooks.<Event>.hooks]] entries,
// when one of those entries runs a command matching `re`.
export function removeHookGroups(text, re) {
  const segs = segments(text);
  const drop = new Set();
  segs.forEach((s, i) => {
    if (!s.array || s.path.length !== 2 || s.path[0] !== 'hooks') return;
    const kids = [];
    for (let j = i + 1; j < segs.length && segs[j].array && segs[j].path.length === 3 && segs[j].path[0] === 'hooks' && segs[j].path[1] === s.path[1] && segs[j].path[2] === 'hooks'; j++) kids.push(j);
    if (kids.some((j) => re.test(String(parseBody(segs[j].lines.join('\n')).command ?? '')))) for (const k of [i, ...kids]) drop.add(k);
  });
  return drop.size ? joinSegments(segs.filter((_, k) => !drop.has(k))) : text;
}

// servers: [{ id, name, value }] (value undefined removes it) or [{ id, skip: true }].
export function applyCodexMcp({ file, servers }, run) {
  const text = readText(file) ?? '';
  const changes = {};
  for (const s of servers) {
    if (s.skip) {
      run.seen.add(s.id);
      continue;
    }
    const label = `${s.value === undefined ? 'remove' : 'set'} [mcp_servers.${s.name}] in ${file}`;
    if (run.step(s.id, { kind: 'toml', file, name: s.name }, hashValue(readMcpTable(text, s.name)), hashValue(s.value), label)) changes[s.name] = s.value;
  }
  if (Object.keys(changes).length && !run.dryRun) writeText(file, writeMcpTables(text, changes));
}
```

```js
// The MCP catalog (mcp/catalog.json) and its rendering into each agent's format.
import { join } from 'node:path';
import { readJson, isObj } from './util.mjs';
import { slash } from './platform.mjs';

const OSES = ['windows', 'mac', 'linux'];
const AGENTS = ['claude', 'codex', 'cursor', 'opencode', 'pi'];

export const loadCatalog = (repo) => readJson(join(repo, 'mcp', 'catalog.json'));

export function catalogProblems(catalog) {
  const out = [];
  for (const [name, s] of Object.entries(catalog?.servers ?? {})) {
    if (!s.npx === !s.http) out.push(`mcp/catalog.json ${name}: needs exactly one of "npx" or "http"`);
    if (typeof s.on !== 'boolean') out.push(`mcp/catalog.json ${name}: "on" must be true or false`);
    for (const os of s.os ?? []) if (!OSES.includes(os)) out.push(`mcp/catalog.json ${name}: unknown os "${os}"`);
    for (const a of Object.keys(s.agents ?? {})) if (!AGENTS.includes(a)) out.push(`mcp/catalog.json ${name}: unknown agent "${a}"`);
  }
  return out;
}

// The servers an agent gets on an OS, with that agent's overrides applied.
export function serversFor(catalog, agent, os) {
  const out = [];
  for (const [name, s] of Object.entries(catalog.servers)) {
    const o = s.agents?.[agent] ?? {};
    if ((s.os && !s.os.includes(os)) || o.skip) continue;
    out.push({ name, npx: s.npx, http: s.http, bearerEnv: s.bearerEnv, env: s.env ?? {}, on: o.on ?? s.on, extra: o.extra ?? {} });
  }
  return out;
}

export class MissingEnv extends Error {
  constructor(name) {
    super(`environment variable ${name} is not set`);
    this.envName = name;
  }
}

const REF = /\$\{([A-Za-z_][A-Za-z0-9_]*)\}/g;

export const envRefs = (s) => [...String(s).matchAll(REF)].map((m) => m[1]);

// {HOME} becomes this machine's home. ${VAR} becomes the agent's own syntax, or,
// with style 'resolve', the variable's value now — for fields an agent cannot
// interpolate (Codex and Pi URLs).
export function expand(s, style, ctx) {
  const env = ctx.env ?? process.env;
  return String(s).replaceAll('{HOME}', () => slash(ctx.home)).replace(REF, (_, v) => {
    if (style === 'cursor') return `\${env:${v}}`;
    if (style === 'opencode') return `{env:${v}}`;
    if (style === 'resolve') {
      if (!env[v]) throw new MissingEnv(v);
      return env[v];
    }
    return `\${${v}}`;
  });
}

const strip = (o) => Object.fromEntries(Object.entries(o).filter(([, v]) => v !== undefined && !(isObj(v) && !Object.keys(v).length)));
const envMap = (s, style, ctx) => Object.fromEntries(Object.entries(s.env).map(([k, v]) => [k, expand(v, style, ctx)]));
const bearer = (s, style, ctx) => (s.bearerEnv ? { Authorization: expand(`Bearer \${${s.bearerEnv}}`, style, ctx) } : undefined);
const npxArgs = (s, ctx) => ['-y', ...s.npx.map((a) => expand(a, 'claude', ctx))];
// On Windows, Claude Code and Pi start local servers through cmd so the npx shim resolves.
const viaCmd = (ctx, args) => (ctx.os === 'windows' ? { command: 'cmd', args: ['/c', 'npx', ...args] } : { command: 'npx', args });
const offFlag = (s) => (s.on ? undefined : false);

export const render = {
  claude: (s, ctx) => strip(s.http
    ? { type: 'http', url: expand(s.http, 'claude', ctx), headers: bearer(s, 'claude', ctx), ...s.extra }
    : { ...viaCmd(ctx, npxArgs(s, ctx)), env: envMap(s, 'claude', ctx), ...s.extra }),
  cursor: (s, ctx) => strip(s.http
    ? { type: 'http', url: expand(s.http, 'cursor', ctx), headers: bearer(s, 'cursor', ctx), ...s.extra }
    : { command: 'npx', args: npxArgs(s, ctx), env: envMap(s, 'cursor', ctx), ...s.extra }),
  opencode: (s, ctx) => strip(s.http
    ? { type: 'remote', url: expand(s.http, 'opencode', ctx), headers: bearer(s, 'opencode', ctx), ...s.extra, enabled: offFlag(s) }
    : { type: 'local', command: ['npx', ...npxArgs(s, ctx)], environment: envMap(s, 'opencode', ctx), ...s.extra, enabled: offFlag(s) }),
  pi: (s, ctx) => strip(s.http
    ? { url: expand(s.http, 'resolve', ctx), headers: bearer(s, 'pi', ctx), ...s.extra, enabled: offFlag(s) }
    : { ...viaCmd(ctx, npxArgs(s, ctx)), env: envMap(s, 'pi', ctx), ...s.extra, enabled: offFlag(s) }),
  codex(s, ctx) {
    if (s.http) return strip({ enabled: offFlag(s), url: expand(s.http, 'resolve', ctx), bearer_token_env_var: s.bearerEnv, ...s.extra });
    // A variable passed through under its own name goes in env_vars; anything else is a literal.
    const passed = Object.keys(s.env).filter((k) => s.env[k] === `\${${k}}`);
    const literal = Object.fromEntries(Object.entries(s.env).filter(([k]) => !passed.includes(k)).map(([k, v]) => [k, expand(v, 'resolve', ctx)]));
    return strip({ enabled: offFlag(s), command: 'npx', args: npxArgs(s, ctx), env_vars: passed.length ? passed : undefined, env: literal, startup_timeout_sec: 30, ...s.extra });
  },
};

export function mcpSection(servers, enableHint) {
  const names = (on) => servers.filter((s) => s.on === on).map((s) => `\`${s.name}\``).join(', ');
  const lines = ['## MCP servers', '', `On by default: ${names(true) || 'none'}.`];
  if (servers.some((s) => !s.on)) lines.push('', `Off by default: ${names(false)}. ${enableHint}`);
  return lines.join('\n');
}
```

```js
// Instruction text for each agent: prompt/core.md with the generated skill
// table, the agent's MCP section and its own notes filled in.
import { join } from 'node:path';
import { readJson, readText, lf } from './util.mjs';
import { skillNames } from './skills.mjs';
import { slash } from './platform.mjs';

const catalogPath = (repo) => join(repo, 'skills', 'global', 'catalog.json');

// Every global skill directory is catalogued, and every catalog entry has one.
export function catalogErrors(repo) {
  const cat = readJson(catalogPath(repo));
  const dirs = skillNames(join(repo, 'skills', 'global'));
  const errors = [];
  for (const d of dirs) if (!cat.skills[d]) errors.push(`skills/global/${d} has no entry in skills/global/catalog.json`);
  for (const n of Object.keys(cat.skills)) if (!dirs.includes(n)) errors.push(`skills/global/catalog.json lists "${n}" but skills/global/${n}/SKILL.md does not exist`);
  for (const [n, m] of Object.entries(cat.skills)) {
    if (!cat.categories.some((c) => c.key === m.category)) errors.push(`skills/global/catalog.json: "${n}" has unknown category "${m.category}"`);
  }
  return errors;
}

export function skillTable(repo) {
  const errors = catalogErrors(repo);
  if (errors.length) throw new Error(`global skill catalog is out of sync:\n  ${errors.join('\n  ')}`);
  const cat = readJson(catalogPath(repo));
  const lines = [`## Global Skills (${Object.keys(cat.skills).length})`];
  for (const c of cat.categories) {
    const names = Object.keys(cat.skills).filter((n) => cat.skills[n].category === c.key);
    if (!names.length) continue;
    lines.push('', `### ${c.title} (${names.length}) — ${c.blurb}`, '', '| Skill | When to use |', '| --- | --- |');
    for (const n of names) lines.push(`| \`${n}\` | ${cat.skills[n].tagline} |`);
  }
  return lines.join('\n');
}

export function renderPrompt(ctx, { title, agent, mcp }) {
  const fill = {
    TITLE: title,
    SKILLS: skillTable(ctx.repo),
    MCP: mcp,
    NOTES: lf(readText(join(ctx.repo, 'agents', agent, 'notes.md')) ?? '').trim(),
    REPO: slash(ctx.repo),
  };
  // A replacer function, so "$&" or "${X}" in the filled text stays literal.
  return lf(readText(join(ctx.repo, 'prompt', 'core.md')))
    .replace(/\{\{(TITLE|SKILLS|MCP|NOTES|REPO)\}\}/g, (_, k) => fill[k])
    .replace(/\n{3,}/g, '\n\n')
    .trim();
}
```

```js
// Pieces every agent adapter uses.
import { existsSync, readdirSync } from 'node:fs';
import { join } from 'node:path';
import { readText, lf } from '../util.mjs';
import { slash } from '../platform.mjs';
import { MissingEnv } from '../mcp.mjs';

export const jsonText = (v) => `${JSON.stringify(v, null, 2)}\n`;

// agents/<agent>/commands/*.md, as managed files in the agent's command directory.
export function commandFiles(ctx, agent, dst) {
  const src = join(ctx.repo, 'agents', agent, 'commands');
  if (!existsSync(src)) return [];
  return readdirSync(src)
    .filter((f) => f.endsWith('.md'))
    .sort()
    .map((f) => ({ id: `${agent}:command:${f}`, file: join(dst, f), content: lf(readText(join(src, f))) }));
}

// guard runs before tool calls and format after edits, both straight from the repo.
export function hookSpecs(ctx, agent) {
  const node = (script) => `node "${slash(join(ctx.repo, 'scripts', 'hooks', script))}"`;
  return [
    { id: `${agent}:hook:guard`, event: 'PreToolUse', matcher: 'Bash|Read|Edit|Write|MultiEdit', command: node('guard.mjs') },
    { id: `${agent}:hook:format`, event: 'PostToolUse', matcher: 'Edit|Write|MultiEdit', command: node('format.mjs') },
  ];
}

// The entry for one server, or a skip marker when a variable it needs right now
// is missing — the machine's existing entry is then left as it is.
export function serverEntry(id, render, warn, entry) {
  try {
    return entry(render());
  } catch (e) {
    if (!(e instanceof MissingEnv)) throw e;
    warn(`${id} left as it is: ${e.message}`);
    return { id, skip: true };
  }
}
```

```js
// Removes what the v1 sync scripts (scripts/sync.ps1 / sync.sh) left behind.
// Every rule matches v1 output only, so it does nothing on a fresh machine and is
// safe on every update. Delete this file once no machine has v1 leftovers.
import { existsSync, readdirSync, statSync, unlinkSync, rmdirSync } from 'node:fs';
import { join } from 'node:path';
import { readText, readJson, writeText, writeJson, isObj, lf } from './util.mjs';
import { removeTree } from './platform.mjs';
import { isV1Prompt } from './managed.mjs';
import { removeHookGroups } from './toml.mjs';

const V1_HOOK = /[\\/]\.agent-hooks[\\/](guard|format)\.mjs/;

function rm(path, run) {
  if (!existsSync(path)) return;
  run.change(`remove-v1 ${path}`);
  if (run.dryRun) return;
  if (statSync(path).isDirectory()) removeTree(path);
  else unlinkSync(path);
}

const only = (dir, names) => existsSync(dir) && readdirSync(dir).every((n) => names.includes(n));

function safeJson(p) {
  try {
    return readJson(p);
  } catch {
    return null;
  }
}

function v1Prompt(path, run) {
  const text = readText(path);
  if (text !== null && isV1Prompt(text)) rm(path, run);
}

function editJson(file, run, edit) {
  const obj = safeJson(file);
  if (!isObj(obj) || !edit(obj)) return;
  run.change(`remove-v1 entries in ${file}`);
  if (!run.dryRun) writeJson(file, obj);
}

function dropV1Hooks(obj) {
  if (!isObj(obj.hooks)) return false;
  let dirty = false;
  for (const [event, groups] of Object.entries(obj.hooks)) {
    if (!Array.isArray(groups)) continue;
    const kept = groups.filter((g) => !(g.hooks ?? []).some((h) => V1_HOOK.test(h.command ?? '')));
    if (kept.length === groups.length) continue;
    dirty = true;
    if (kept.length) obj.hooks[event] = kept;
    else delete obj.hooks[event];
  }
  return dirty;
}

// Copies v1 put directly in the home directory.
export function cleanHome(ctx, run) {
  const h = ctx.home;
  rm(join(h, 'HARNESS.md'), run);
  rm(join(h, 'PLAYBOOK.md'), run);
  if (only(join(h, '.agent-hooks'), ['guard.mjs', 'format.mjs'])) rm(join(h, '.agent-hooks'), run);
  const templates = join(h, 'MCP-Templates');
  if (existsSync(templates) && readdirSync(templates).every((n) => n.endsWith('.json') || n === 'README.md')) rm(templates, run);
  v1Prompt(join(h, 'AGENTS.md'), run);
}

// v1 mirrored skills/global wholesale, so its two data files sit in every agent's skill dir.
export function cleanSkillDir(dir, run) {
  rm(join(dir, 'catalog.json'), run);
  rm(join(dir, 'skill-rules.json'), run);
}

export function cleanAgent(ctx, agent, catalogNames, run) {
  const h = ctx.home;
  if (agent === 'claude') {
    editJson(join(h, '.claude', 'settings.json'), run, (obj) => {
      let dirty = dropV1Hooks(obj);
      // v1 also merged mcpServers into settings.json, where Claude Code never reads them.
      if (isObj(obj.mcpServers) && Object.keys(obj.mcpServers).every((n) => catalogNames.includes(n))) {
        delete obj.mcpServers;
        dirty = true;
      }
      return dirty;
    });
  }
  if (agent === 'codex') {
    const profiles = join(h, '.codex', 'profiles');
    if (only(profiles, ['development.toml', 'full.toml', 'minimal.toml', 'switch.ps1', 'switch.sh'])) rm(profiles, run);
    const file = join(h, '.codex', 'config.toml');
    const text = readText(file);
    const next = text === null ? null : removeHookGroups(text, V1_HOOK);
    if (next !== text) {
      run.change(`remove-v1 hooks in ${file}`);
      if (!run.dryRun) writeText(file, next);
    }
  }
  if (agent === 'cursor') {
    v1Prompt(join(h, '.cursor', 'global-rules.md'), run);
    v1Prompt(join(h, '.cursor', 'rules', 'global-rules.md'), run);
    editJson(join(h, '.cursor', 'mcp.json'), run, (obj) => {
      let dirty = false;
      for (const [name, v] of Object.entries(isObj(obj.mcpServers) ? obj.mcpServers : {})) {
        if (catalogNames.includes(name) && v?.enabled === false) {
          delete obj.mcpServers[name];
          dirty = true;
        }
      }
      return dirty;
    });
  }
  if (agent === 'opencode') {
    const old = join(h, '.opencode');
    v1Prompt(join(old, 'AGENTS.md'), run);
    const cfg = safeJson(join(old, 'opencode.json'));
    if (isObj(cfg) && Object.keys(cfg).every((k) => ['$schema', 'lsp', 'mcp'].includes(k))) rm(join(old, 'opencode.json'), run);
    if (existsSync(join(old, 'skills', 'catalog.json'))) rm(join(old, 'skills'), run);
    const src = join(ctx.repo, 'agents', 'opencode', 'commands');
    const ours = existsSync(src) ? readdirSync(src) : [];
    if (only(join(old, 'command'), ours)) rm(join(old, 'command'), run);
    // v2 writes commands/ (OpenCode's documented name); v1 wrote command/.
    const singular = join(h, '.config', 'opencode', 'command');
    for (const f of ours) {
      const t = readText(join(singular, f));
      if (t !== null && lf(t) === lf(readText(join(src, f)))) rm(join(singular, f), run);
    }
    if (!run.dryRun && existsSync(singular) && !readdirSync(singular).length) rmdirSync(singular);
  }
}
```

```js
// Applies agents' plans: skill links, instruction blocks, managed files, JSON and
// TOML entries, the v1 cleanup, and removal of whatever the repo stopped shipping.
import { join } from 'node:path';
import { readText, writeText } from './util.mjs';
import { loadState, saveState } from './state.mjs';
import { makeRun } from './run.mjs';
import { globalSkills, packSkillSets } from './skills.mjs';
import { syncLinks, pruneLinks } from './links.mjs';
import { applyBlock, removeBlock, applyFile, removeFile } from './managed.mjs';
import { applyJson, removeJson } from './jsonfile.mjs';
import { applyCodexMcp } from './toml.mjs';
import { loadCatalog, serversFor, mcpSection } from './mcp.mjs';
import { renderPrompt } from './prompt.mjs';
import { cleanHome, cleanAgent, cleanSkillDir } from './legacy.mjs';
import claude from './agents/claude.mjs';
import codex from './agents/codex.mjs';
import cursor from './agents/cursor.mjs';
import opencode from './agents/opencode.mjs';
import pi from './agents/pi.mjs';

export const ADAPTERS = { claude, codex, cursor, opencode, pi };

// The adapter's plan plus the rendered instruction text and the server list.
export function buildPlan(ctx, name, warn = () => {}) {
  const adapter = ADAPTERS[name];
  if (!adapter) throw new Error(`unknown agent "${name}" — known: ${Object.keys(ADAPTERS).join(', ')}`);
  const catalog = loadCatalog(ctx.repo);
  const servers = serversFor(catalog, name, ctx.os);
  const plan = adapter.plan(ctx, servers, warn);
  const text = renderPrompt(ctx, { title: adapter.title, agent: name, mcp: mcpSection(servers, adapter.enableHint) });
  return { ...plan, servers, catalogNames: Object.keys(catalog.servers), prompt: { ...plan.prompt, text } };
}

export const packRoot = (ctx, set) => join(ctx.home, set.pack, ...set.sub.split('/').filter(Boolean));

// Cursor reads user rules only from its settings UI, so the text goes to a file to paste.
function writeManual(file, text, run) {
  if (readText(file) === text) return;
  run.change(`write ${file}`);
  run.note(`Cursor rules changed — paste ${file} into Cursor Settings → Rules → User Rules`);
  if (!run.dryRun) writeText(file, text);
}

function applyAgent(ctx, name, packs, run) {
  const plan = buildPlan(ctx, name, run.warn);
  syncLinks(ctx, { ...globalSkills(ctx.repo), dst: plan.skills.global }, run);
  cleanSkillDir(plan.skills.global, run);
  for (const set of packSkillSets(ctx.repo, packs)) syncLinks(ctx, { src: set.src, names: set.names, dst: plan.skills.pack(packRoot(ctx, set)) }, run);
  if (plan.prompt.manual) writeManual(plan.prompt.manual, plan.prompt.text, run);
  else applyBlock({ id: plan.prompt.id, file: plan.prompt.file, content: plan.prompt.text }, run);
  for (const f of plan.files) applyFile(f, run);
  for (const j of plan.json) applyJson(j, run);
  for (const t of plan.toml) applyCodexMcp(t, run);
  cleanAgent(ctx, name, plan.catalogNames, run);
}

// Removes what this agent had installed that the run did not touch (the repo
// stopped shipping it, or the agent is being uninstalled).
function pruneAgent(name, run) {
  const stale = Object.entries(run.state.entries)
    .filter(([id, e]) => e.agent === name && !run.seen.has(id))
    .map(([id, e]) => ({ id, ...e }));
  const jsonByFile = new Map();
  for (const it of stale) {
    if (it.pinned) {
      delete run.state.entries[it.id];
      run.note(`no longer shipped, left as it is: ${it.id}`);
    } else if (it.kind === 'file') removeFile(it, run);
    else if (it.kind === 'block') removeBlock(it, run);
    else if (it.kind === 'toml') applyCodexMcp({ file: it.file, servers: [{ id: it.id, name: it.name, value: undefined }] }, run);
    else jsonByFile.set(it.file, [...(jsonByFile.get(it.file) ?? []), it]);
  }
  for (const [file, items] of jsonByFile) removeJson(file, items, run);
}

function uninstallAgent(ctx, name, packs, run) {
  const plan = buildPlan(ctx, name, run.warn);
  pruneLinks(ctx, plan.skills.global, () => false, run);
  for (const set of packSkillSets(ctx.repo, packs)) pruneLinks(ctx, plan.skills.pack(packRoot(ctx, set)), () => false, run);
  pruneAgent(name, run);
}

export function runInstall(ctx, { agents, packs, dryRun = false, resolutions = {}, uninstall = false }) {
  for (const name of agents) {
    if (!ADAPTERS[name]) throw new Error(`unknown agent "${name}" — known: ${Object.keys(ADAPTERS).join(', ')}`);
  }
  const state = loadState(ctx.local);
  const run = makeRun({ state, resolutions, dryRun });
  if (!uninstall) cleanHome(ctx, run);
  for (const name of agents) {
    run.agent = name;
    if (uninstall) uninstallAgent(ctx, name, packs, run);
    else {
      applyAgent(ctx, name, packs, run);
      pruneAgent(name, run);
    }
  }
  if (!dryRun) {
    state.agents = uninstall ? state.agents.filter((a) => !agents.includes(a)) : [...new Set([...state.agents, ...agents])].sort();
    if (!uninstall) state.packs = packs;
    saveState(ctx.local, state);
  }
  return run.report;
}
```

```js
// Read-only health check. Its core is a dry-run update — pending changes are
// drift, conflicts are conflicts — plus the checks an update cannot make.
import { existsSync, readdirSync } from 'node:fs';
import { join } from 'node:path';
import { spawnSync } from 'node:child_process';
import { readText, readJson, lf } from './util.mjs';
import { loadState } from './state.mjs';
import { runInstall, buildPlan, packRoot } from './engine.mjs';
import { globalSkills, packSkillSets, PACKS } from './skills.mjs';
import { catalogErrors } from './prompt.mjs';
import { loadCatalog, catalogProblems, serversFor, envRefs } from './mcp.mjs';
import { samePath } from './platform.mjs';
import { LSP_PLUGINS } from './agents/claude.mjs';

// Repo self-check (also `node harness.mjs check`).
export function repoProblems(ctx) {
  const out = [...catalogErrors(ctx.repo), ...catalogProblems(loadCatalog(ctx.repo))];
  const core = readText(join(ctx.repo, 'prompt', 'core.md')) ?? '';
  for (const p of ['{{TITLE}}', '{{SKILLS}}', '{{MCP}}', '{{NOTES}}']) if (!core.includes(p)) out.push(`prompt/core.md is missing ${p}`);
  const harness = spawnSync(process.execPath, [join(ctx.repo, 'scripts', 'gen-harness.mjs'), '--check'], { encoding: 'utf8' });
  if (harness.status !== 0) out.push('HARNESS.md is out of date — run: node scripts/gen-harness.mjs');
  return out;
}

export async function doctor(ctx, { deep = false } = {}) {
  const found = [];
  const fail = (msg) => found.push({ level: 'fail', msg });
  const warn = (msg) => found.push({ level: 'warn', msg });
  for (const p of repoProblems(ctx)) fail(p);
  const state = loadState(ctx.local);
  if (!state.agents.length) {
    warn('nothing is installed on this machine yet — run: node harness.mjs install --agents <list>');
    return found;
  }
  const report = runInstall(ctx, { agents: state.agents, packs: state.packs, dryRun: true });
  if (report.changes.length) {
    const shown = report.changes.slice(0, 30).join('\n    ');
    warn(`update would make ${report.changes.length} change(s):\n    ${shown}${report.changes.length > 30 ? '\n    …' : ''}`);
  }
  for (const c of report.conflicts) fail(`conflict ${c.id}: ${c.msg}`);
  for (const w of report.warnings) warn(w);
  gitChecks(ctx, warn);
  for (const dir of orphanSkillDirs(ctx, state)) warn(`no plan covers this skill directory (left from a removed pack or sub-pack?): ${dir}`);
  for (const v of missingEnv(ctx, state)) warn(`environment variable ${v} is not set, but a server that is on by default needs it`);
  if (deep) await deepChecks(ctx, state, warn);
  return found;
}

function gitChecks(ctx, warn) {
  const git = (...args) => spawnSync('git', ['-C', ctx.repo, ...args], { encoding: 'utf8' });
  const branch = git('rev-parse', '--abbrev-ref', 'HEAD').stdout?.trim();
  if (branch && branch !== 'master') warn(`this checkout is on "${branch}" — agents link into it, so that branch is what they run`);
  const dirty = git('status', '--porcelain', '--', 'skills', 'agents', 'prompt', 'mcp', 'scripts/hooks').stdout?.trim();
  if (dirty) warn(`uncommitted changes in shipped content (edits made through the links land here):\n    ${dirty.split('\n').join('\n    ')}`);
}

const AGENT_DIRS = ['.claude', '.codex', '.cursor', '.opencode', '.pi'];
const SKIP_DIRS = new Set(['node_modules', '.git', '.venv', 'venv', '__pycache__']);

function orphanSkillDirs(ctx, state) {
  const planned = [];
  for (const name of state.agents) {
    const plan = buildPlan(ctx, name);
    for (const set of packSkillSets(ctx.repo, state.packs)) planned.push(plan.skills.pack(packRoot(ctx, set)));
  }
  const out = [];
  const walk = (dir, depth) => {
    if (depth > 3 || !existsSync(dir)) return;
    for (const e of readdirSync(dir, { withFileTypes: true })) {
      if (!e.isDirectory() || SKIP_DIRS.has(e.name)) continue;
      const p = join(dir, e.name);
      if (!AGENT_DIRS.includes(e.name)) {
        walk(p, depth + 1);
        continue;
      }
      const skills = join(p, 'skills');
      if (existsSync(skills) && readdirSync(skills).length && !planned.some((q) => samePath(q, skills))) out.push(skills);
    }
  };
  for (const pack of Object.values(PACKS)) walk(join(ctx.home, pack), 0);
  return out;
}

function missingEnv(ctx, state) {
  const catalog = loadCatalog(ctx.repo);
  const need = new Set();
  for (const name of state.agents) {
    for (const s of serversFor(catalog, name, ctx.os)) {
      if (!s.on) continue;
      for (const v of [...envRefs(s.http ?? ''), ...(s.bearerEnv ? [s.bearerEnv] : []), ...Object.values(s.env).flatMap(envRefs)]) need.add(v);
    }
  }
  return [...need].filter((v) => !process.env[v]).sort();
}

async function deepChecks(ctx, state, warn) {
  const names = globalSkills(ctx.repo).names;
  const tool = (cmd, args) => spawnSync(cmd, args, { cwd: ctx.home, encoding: 'utf8', timeout: 180000, shell: process.platform === 'win32' });
  if (state.agents.includes('opencode')) {
    const out = tool('opencode', ['debug', 'skill']).stdout ?? '';
    const at = out.search(/\[\s*\{/);
    let loaded = null;
    try {
      loaded = at === -1 ? null : new Set(JSON.parse(out.slice(at)).map((s) => s.name));
    } catch {
      loaded = null;
    }
    if (!loaded) warn('opencode debug skill gave no skill list — is opencode installed?');
    else if (names.some((n) => !loaded.has(n))) warn(`OpenCode does not load: ${names.filter((n) => !loaded.has(n)).join(', ')}`);
  }
  if (state.agents.includes('codex')) {
    const r = tool('codex', ['debug', 'prompt-input', 'doctor']);
    if (r.status !== 0) warn('codex debug prompt-input failed — is codex installed?');
```

```js
// Installs and maintains this repo's agent harness on the current machine.
// Design: docs/harness-v2.md.

import { dirname, join } from 'node:path';
import { makeContext, isWorktree } from './lib/platform.mjs';
import { loadState } from './lib/state.mjs';
import { runInstall } from './lib/engine.mjs';
import { PACKS } from './lib/skills.mjs';
import { doctor, repoProblems } from './lib/doctor.mjs';

  node harness.mjs install --agents claude,codex,cursor,opencode,pi [--packs ${Object.keys(PACKS).join(',')}] [--dry-run]
  node harness.mjs update [--dry-run]
  node harness.mjs doctor [--deep]
  node harness.mjs resolve                  list conflicts

  node harness.mjs resolve keep <id|all>    keep this machine's version and stop managing it

add --verbose to list every change`;

// HARNESS_HOME points the installer at another home (tests use it); its state then
// lives in that home too, so the real machine state is never touched.
const home = process.env.HARNESS_HOME || undefined;
const ctx = makeContext({ repo, home, local: home ? join(home, '.harness-local') : undefined });
const [cmd, ...args] = process.argv.slice(2);
const has = (flag) => args.includes(`--${flag}`);
const list = (flag) => {
  const i = args.indexOf(`--${flag}`);
  return i === -1 ? null : (args[i + 1] ?? '').split(',').map((s) => s.trim()).filter(Boolean);
};

function die(msg, code = 2) {
  console.error(msg);
  process.exit(code);
}

// Links make the checkout live; a worktree must never become what agents run.
function liveGuard() {
  if (isWorktree(repo) && !home) die('This checkout is a git worktree: links would point into it. Run install/update from the main checkout.');
}

function printReport(r) {
  if (!r.changes.length) console.log('no changes');
  else if (has('verbose') || r.changes.length <= 40) {
    console.log(`changes (${r.changes.length}):`);
    for (const c of r.changes) console.log(`  ${c}`);
  } else {
    const byVerb = new Map();
    for (const c of r.changes) byVerb.set(c.split(' ')[0], (byVerb.get(c.split(' ')[0]) ?? 0) + 1);
    console.log(`changes (${r.changes.length}): ${[...byVerb].map(([v, n]) => `${v} ×${n}`).join(', ')} — add --verbose to list them`);
  }
  for (const w of r.warnings) console.log(`warning: ${w}`);
  for (const n of r.notes) console.log(`note: ${n}`);
  if (!r.conflicts.length) return 0;
  console.log(`conflicts (${r.conflicts.length}) — nothing was written for these:`);
  for (const c of r.conflicts) console.log(`  ${c.id}\n      ${c.msg}`);
  console.log('  resolve with: node harness.mjs resolve repo <id|all>   or   node harness.mjs resolve keep <id|all>');
  return 1;
}

const state = loadState(ctx.local);
switch (cmd) {
  case 'install': {
    liveGuard();
    const agents = list('agents') ?? die(USAGE);
    process.exit(printReport(runInstall(ctx, { agents, packs: list('packs') ?? Object.keys(PACKS), dryRun: has('dry-run') })));
  }
  case 'update': {
    liveGuard();
    if (!state.agents.length) die('nothing installed yet — run: node harness.mjs install --agents <list>');
    process.exit(printReport(runInstall(ctx, { agents: state.agents, packs: state.packs, dryRun: has('dry-run') })));
  }
  case 'resolve': {
    liveGuard();
    const [how, id] = args;
    if (!how) {
      const r = runInstall(ctx, { agents: state.agents, packs: state.packs, dryRun: true });
      if (!r.conflicts.length) console.log('no conflicts');
      for (const c of r.conflicts) console.log(`${c.id}\n    ${c.msg}`);
      process.exit(0);
    }
    if (!['repo', 'keep'].includes(how) || !id) die(USAGE);
    process.exit(printReport(runInstall(ctx, { agents: state.agents, packs: state.packs, resolutions: { [id]: how } })));
  }
  case 'uninstall': {
    liveGuard();
    const agents = list('agents') ?? die(USAGE);
    process.exit(printReport(runInstall(ctx, { agents, packs: state.packs, uninstall: true })));
  }
  case 'doctor': {
    const found = await doctor(ctx, { deep: has('deep') });
    if (!found.length) console.log('all good');
    for (const f of found) console.log(`${f.level === 'fail' ? 'FAIL' : 'warn'}: ${f.msg}`);
    process.exit(found.some((f) => f.level === 'fail') ? 1 : 0);
  }
  case 'check': {
    const problems = repoProblems(ctx);
    for (const p of problems) console.error(`FAIL: ${p}`);
    if (!problems.length) console.log('repo is consistent');
    process.exit(problems.length ? 1 : 0);
  }
  default:
    die(USAGE, cmd ? 2 : 0);
}
```

````markdown
Narrow bridge. Run these commands as written, in this order, from the repo root.

## Declare what it costs

Every pack skill states its cost tier on a `compatibility:` line. The first token is one of four

compatibility: "offline — no scripts, no network, no credentials"
compatibility: "network — public APIs, no credentials required; optional NCBI_API_KEY raises rate limits"
compatibility: "local-tools — needs a TeX engine (Tectonic auto-installs its own packages)"

**The propagation rule, which is the point of the convention:**

> A skill may not instruct the agent to invoke a `paid` skill unless the calling skill itself

fail with an error. It charges, silently, and the only way to find out is the invoice.
````

````markdown
## ⚙️ 怎么装、怎么同步

```bash
node harness.mjs install --agents claude --dry-run   # 先看会做什么
node harness.mjs install --agents claude,codex       # 装哪几个 agent 由你点名
git pull && node harness.mjs update                  # 之后每次更新
node harness.mjs doctor                              # 体检:漂移、冲突、遗留、缺的环境变量
```

三条原理:

- **skill 是链接,不是拷贝**:每个 agent 的 skill 目录里放的是指回本仓库的链接(Windows 用 junction),
  只有一份文件;在本机改 skill 就是在改仓库,`git status` 里直接看得到。
- **按条目合并**:仓库只管它定义的条目(某个 MCP、某个 hook、提示词里标记圈出的一段),agent 配置
  文件里其他东西(模型、登录、你自己加的 MCP 和插件)一律不碰。
- **三方比较**:本机改过仓库管的条目,安装器不覆盖,报冲突,用 `node harness.mjs resolve` 决定用哪边。

## 📜 Core Principles(6 条,启动即载入)

每个 agent 的 system prompt 顶部是 6 条**可执行**原则(不是抽象口号,带自检):

1. **Think before acting** — 说清假设;多种解释都摆出来,不默默选一个。
2. **Simplicity first** — 最小可行代码;200 行能 50 行做完就重写。
3. **Surgical changes** — 只碰任务需要的;每一行改动都能追溯到需求。
4. **Exhaust options before giving up** — "不行"是待验证的假设,不是结论。
5. **Verify before claiming success** — 用证据(跑/测/看)证明,再说"完成"。
6. **Preserve context and align with the goal** — 不为子任务牺牲真实目标。

> 对齐 andrej-karpathy-skills 的 `karpathy-guidelines`,装在 system-prompt 层,零 skill-match 开销。
> 源头是 `prompt/core.md`,安装时拼进每个 agent 的指令。
````
