# 提纲矩阵：论据的触发器（Outline Skills）

> 当具象化/情景化之后还需要更多论据方向时，用这套矩阵触发思路。
> 适合建议类题目（should / the best way to / it is important to...）。

## 一、影响维度矩阵（往哪个方向想）

### Society（社会层面）

| 分支 | 角度 |
|------|------|
| 稳（社会稳定/运行） | employment 就业、population density 人口密度、cultural conflict 文化冲突 |
| 文（文化） | extension/expansion 传播、inheritance 传承、public awareness/propaganda 公众意识 |

### Individuals（个人层面）

| 分支 | 角度 |
|------|------|
| 健康 | physical 身体、mental 心理 |
| 社交 | social relationship 人际关系、social status 社会地位、interpersonal skills 社交技能、leadership/collaboration 领导力/协作 |

## 二、支持/反对论证矩阵（怎么想理由）

### 支持（For）

| 维度 | 思路 |
|------|------|
| 必要性 Necessity | Benefits：带来好处，好处重要且必须；Solving Problems：解决实际问题，问题紧急 |
| 可行性 Feasibility | 有人力、物力、财力、知识、时间、技术、经验去实施；即使有困难也有办法解决 |
| 实际效果 Effect | Effective：效果好有保障；Acceptable：虽不完美但有理由相信值得做 |

### 反对（Against）

| 维度 | 思路 |
|------|------|
| 不必要 | 好处不被特定人群需要；好处是特定人群已有的；问题不存在/不严重；Alternative：好处可以由更好的方法获得 |
| 风险 Risks | Downsides：很多弊端；Counterproductive：实际上起反作用，与初衷恰好相反 |
| 让步段写法 | Risk management：即使有风险，但风险可控、可预防、可被减少或解决 |
| 不可行 | 没有能力/知识/条件实施；特定人群没有能力 |
| 效果存疑 | Ineffective：没找到问题根本原因；Not worthwhile：实际收益低（与成本、风险、代价比较） |

## 三、三种提纲形态（以"所有大学生应修科学课"为例）

### One-sided（一边倒）

```
Thesis: 我不同意
Argument 1: 不必要（很多专业与自然科学无关；初高中已学过基础科学）
Argument 2: 有害（课程难→挫败感→打击学习热情；占用专业学习时间）
Argument 3: 课程效果值得怀疑（强迫学习无动力；教授课堂无聊）
Conclusion: 不同意
```

### Argumentative（让步反驳）

```
Thesis: 同意
Argument 1: 科学常识是必须的
Argument 2: 培养抽象化、概念化的理科思维
Concession: 科学课确实难，容易挫败
Rebuttal: 困难并非不可逾越（可以不设严格考试；增强课堂趣味）
Conclusion: 同意
```

### Two-sided（两边论述）

```
Thesis: 不同意
Body A: 支持方的理由（科学常识必须；培养理科思维）
Body B: 反对方的理由（不必要；有害；效果存疑）  ← 段落长度 > Body A
Conclusion: 不同意
```

⚠️ **Two-sided 的两个细节**：文章的立场放在较后的主体段写；立场方段落更长（Against > For）。
