# 冲 7 语言升级：名词化 + Hedging + 引用动词

> 适用场景：学生的 TR/CC 没问题，但 LR 卡在 6-6.5，句子"读起来像口语"。
> 两个技巧各管一件事：**名词化改句子骨架**（谁做主语），**Hedging 改语气**（别说太死）。

## 一、名词化（动词/形容词 → 名词）

**原理**：英文学术写作的习惯是**名词多、动词少**。动词扎堆像讲故事，把关键动作变成名词，语气立刻沉稳。

| 原词 | 名词化 |
|------|--------|
| pollute | pollution |
| consume | consumption |
| expect too much | high expectations |
| lack (awareness) | the lack of awareness |
| spread rapidly | the rapid spread |
| regulate | regulation |

**三步操作**：
1. 找到句子里的动词（preserved、allowed）
2. 把主要动词变名词做主语（**The preservation** of old buildings by local authorities...）
3. 原来的主语降级为 of... / by...

**对比示例**：
- ❌ Because people **don't care about** the environment, this **has caused** many health problems.
- ✅ **The lack of environmental awareness** has caused many health problems.

**⚠️ 副作用**：一段话名词化 **1-2 次**就够。全是名词像法律条文（The implementation of the regulation regarding the limitation of the consumption...），考官会晕。判断标准：读完像讲故事→加一处；像法律文书→改回几个动词；稳重不拗口→刚好。

## 二、Hedging（模糊限制语：不是心虚，是学术惯例）

| 强度 | 表达 | 示例 |
|------|------|------|
| 弱（最安全） | may / might / could | This **may** lead to... |
| 中 | tend to / appear to / is likely to | Young people **tend to** prefer... |

**改写对照**：will be solved → **may be addressed**；causes → **may contribute to**；have found → **appear to have identified**

**⚠️ 一篇文章 2-3 处就够**，每句都 may 反而显得没立场。

## 三、口语词替换表（改骨架 + 换表面，一起用）

| 口语 | 学术 |
|------|------|
| a lot of | many / numerous / a significant number of |
| big / small | significant / substantial / marginal |
| good / bad | beneficial / detrimental / favourable / adverse |
| important | crucial / essential / vital |
| think / believe | argue / contend / maintain / assert |
| show | demonstrate / reveal / indicate |
| help | facilitate / enable |
| kids / old people | children / young people；the elderly / older generations |
| thing | aspect / factor / element / issue |
| more and more | an increasing number of / increasingly |

**特别提醒**：不是装高级——不确定怎么用的词就别用，用错比不用更扣分。

## 四、引用动词三级（引入观点的力度 = 你的态度）

| 力度 | 动词 | 暗示 | 用途 |
|------|------|------|------|
| 中性 | state, note, point out | "他这么说了，我不评价" | Discuss both views 客观转述 |
| 强势 | argue, claim, assert, contend | "他在力推"（暗示未必对） | 你准备反驳的观点 |
| 弱势 | suggest, imply, assume | "他暗示的，未必成立" | 显得严谨、留余地 |

- Some people **argue** that homework is a waste of time. However, this view overlooks...（要反驳→强势）
- Supporters **note** that homework helps students review.（客观转述→中性）

**⚠️** 一篇 2-3 个就够；argue / suggest / claim / note 先用熟，再加 contend / assert。

## 五、自检清单（学生写完作文后逐项打勾）

- [ ] 名词化 1-2 处（不是每句都名词化）
- [ ] Hedging 2-3 处（may / tend to / appear to / likely to）
- [ ] 引用观点用了至少 1 个 7+ 引用动词（非 think/believe/say）
- [ ] 无 kids / a lot of / thing / good / bad
- [ ] 因果表达至少 2 个不同（非 because / so）
- [ ] 连接词至少 3 种不同功能（furthermore / however / therefore / for instance）

## 六、综合实战示范（三件套叠加）

题目：Some people think that children should not be given homework. To what extent do you agree?

> Some people **argue** that homework places unnecessary pressure on children and **may** hinder their development. However, **the completion of** regular assignments **can** contribute significantly to children's academic progress. **The completion of** assignments at home **enables** students to review and practise the material covered during lessons, which **tends to** result in better retention of knowledge. **Furthermore**, homework **facilitates** the development of independent study habits that **are likely to** benefit them throughout their academic careers. **Admittedly**, **excessive** homework **may cause** stress. **Nevertheless**, when given in appropriate amounts, the benefits clearly outweigh the drawbacks.

检查点：argue（引用动词）+ the completion of（名词化）+ can/tends to/are likely to/may（hedging）+ enables/facilitates/excessive（口语词替换）+ Furthermore/Admittedly/Nevertheless（三种功能连接词）
