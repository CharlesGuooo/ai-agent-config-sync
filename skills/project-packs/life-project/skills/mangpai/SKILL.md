- **⚠ 夏令时：1986–1991 年出生、且生日落在 4 月中～9 月中的，必须问一句**——

## 第三步 · 入局（读 `00` + `01` + `02` + `03` + `04`）

按原文次序，逐项写出结论：

1. **清纯** —— 五行清纯？十神清纯？（十神里只有正财偏财不存在清浊问题）
2. **流通** —— 财富的走向、要制的东西的来路
3. **党势** —— 哪些字是一党（体：印比禄；用：财官；中神：食伤），两党力量是否相当
   　　**比劫与印先分主宾再入党**：主位（日时）的比劫＝自己的身体，计入体；**宾位（年月）的比劫＝合作之人**（合伙人／股东／投资方），**不计入体**，另作「外来分财者」读［`03-geju.md` §四 第3格 / `00-gangling.md` §三］
4. **意向** —— 先看天干做何事（有合先看合 → 无合看生 → 看冲 → 看穿），再查地支有何意
   　　**合要先数个数再定层级**：二争一＝争合，合不走（`04-zuoyong.md` §一「合的裁决顺序」）
   　　两大抓手在 `03-geju.md`：**五种伤官格**（§二）与**十神八组合**（§三）
5. **体用与主宾** —— 谁是体、谁是用；这个财／官是自己的还是别人的（主位／宾位）
6. **做功** —— 到底在制谁、合谁、开哪个库；核心那个字是什么
   　　**并明写：成格之字是哪个（要保护）、败格之字是哪个（要制化）**［`03-geju.md` §四］

用 `04-zuoyong.md` 解读脚本给出的每一条作用关系——**先过 §〇 总纲那两条闸门**（「凶制吉、吉制吉，坏事」「相生就是通关」），再判这条关系是做功还是坏功；然后用 `01/02` 给核心字取象。

## 第四步 · 断专题

按第零步的选择读对应参考文件，**走该文件末尾的「断法链路」**，不要跳步。

各专题共同的骨架（原文：「所有的东西都是一条主线」）：

```
定宫（正宫＋副宫） → 以宫定星（不要以星定宫） → 查三要素（宫・星・财）

**断语使用纪律**（原文原话）：
- **断语是判据第 3 层，套之前先过第 1 层「做功」。**同一个字在不同盘里做的功不同，断语适用与否也不同——

  **先问「这个字来了在做什么功」，再决定套哪条断语。**

- 「八字基础知识相当于单词，金口决相当于语法。」

## 第五步 · 应期（读 `10-yingqi.md`）

```
限运（一字八年，看这件事落在第几个字）
  → 大运（动宫？动星？有没有把做功之神合走冲走＝反局？）
  → 流年（合者主到、冲者主动、墓者主收、穿者主伤；原局有合见冲为应，有冲见合为应）
```

**原局看贵贱，大运看大事，流年看应期。**
反局判定务必做：原局反局＝破格；大运反局＝大凶；流年反局＝小凶；两者重合＝凶上加凶。

> **⚠ 判反局之前先过两道闸门**——反局的前提是做功之神**真的**被合走／冲走：
> 1. **争合**：做功之神是**两个以上**同字、来合的只有**一个**？那是争合，「合不走的东西……只能说合动了他」[ch14]，**不构成反局**。看脚本有没有出 `[争合]` 条、原记录尾部有没有 `※争合`。
> 2. **合去的条件**：被合的是**实干有强根**吗？合去只对「被大运换去／虚透到大运／力量悬殊的弱者」成立，实干强根最多**合住／合动**（`04-zuoyong.md` §一）。
>
> 冲那边本来就有对称的一条：「**大运两个为冲动**（地支有两个寅，大运申冲两个叫冲动，**打不死人家**）」[ch16]。合缺的就是这一条，**别再漏**。

1. **断语照原文措辞**，不改写、不软化；引用时标出章节（如 `[金口诀·ch27]`）。
2. **执行原文自带的执业规矩** [ch39]：

   即：**寿元、残疾、疾病、死期、牢狱这类内容，用户不问就不主动展开**；用户问了，落到「某年某月留意」的提醒，而不是断言。这条只管「不主动说」，**不改任何断语的措辞**。
3. 涉及第三方（配偶、父母、子女、同事）的凶断，只作命理陈述，不作事实指控。
4. 区分「命理断语」与「事实」：不要把断语说成对某个真实的人的鉴定结论。
5. 标注**置信度**：时辰不确定、藏干边界、格局模糊、断语互相打架时，明说「置信度低」。
6. 每次输出末尾带免责声明。
7. **每次交付都带「大白话节」**——写给完全不懂命理的人，零术语，不论出不出 PDF、不论看几个专题。

8. **一律第三人称称呼盘的主人。****来问的人不一定是盘的主人**，可能在给孩子、伴侣、父母看。

   ```
   命主（或用户给的称呼） = 盘的主人   → 第三人称，用于一切关于此人命运的陈述

   判断口诀：**这句话是在说「这个人怎么样」，还是在对「读报告的人」提要求？**
   原文自己就分了这两个角色——ch5「命主本人」、ch22「表命主做功的方向」 vs ch39「**客户**不问不说」。
   涉及六亲写「命主的父亲／配偶」，不写「你爸／你老婆」。**这条对聊天直接解读同样生效**，不只管 PDF。
   PDF 侧由 `output/build_pdf.py` 的人称 lint 强制（白名单＝`.ask` / `.nb` / `.q`）。

## 常见错误（别犯）

| 错误 | 正确做法 |
|---|---|
| 凭记忆排四柱 / 算大运 | 一律跑 `paipan.py` |
| 一上来就问「这个十神是喜是忌」 | 先定**成格之字与败格之字**，再看它在做什么功（判据第 1 层）。旺衰落第 5 层，用了要标注 |
| 把类象词典当断语库，见「印」就断学历 | 先由做功定出**核心字**，再对该字查 `01-leixiang.md`（判据第 3 层） |
| 见「相生」就当好事 | 先判断这个生是把「用」泄给了「体」（**通关**）还是构成流通（`04-zuoyong.md` §〇） |
| 拿格局套案例 | 原文：「**千万不要拿格局套案例**」「八字是要活看的」 |
| 见 `[天干五合]×2` 就断「两个字都被合走」 | **先数个数**：二争一＝**争合**，合不走、合不住，只作合动／合像［`04` §一］。`[六合]×N`、`[穿]×N` 同理。脚本已直接出 `[争合]`／`[争穿]` 聚合条 |
| 把「合」一律读成「把这个字拿掉了」 | 合分**合绊／合动／合去／合制／合像**五级，**合去是有前提的**（虚透、被换去、力量悬殊）。实干有强根者最多合住［`04` §一］ |
| 单条金口诀直断 | 至少三条互证，且先过全盘生克刑冲 |
| 用传统六害／六破／传统驿马 | 用盲派定义（穿、四破、整组三合对冲的驿马） |
| 以星定宫 | **以宫定星，宫大于星** |
| 不分主宾就断「他的财」「他的官」 | 年月＝宾位（外、早年、别人），日时＝主位（自己） |
| **只把主宾用在财官上，比劫印照单全收进「体」** | **比劫印也要分主宾**：宾位比劫＝合作之人（合伙／股东／融资），不计入体。漏这一步会把党势算多，还会漏掉整条「合伙融资」的象［`03-geju.md` §四 第3格］ |
| 见「本盘无食伤」就断「官杀无制」 | **制有合制／克制／刑制／穿制四种，合制效率最高**［ch13］。比劫合官杀也是制［ch28］。判「官杀当财」先过 `09-zhiye.md` §三 的四种制闸门 |
| 走了四种制的闸门，但**只查原局** | **查制要分两层**：原局定先天格局，**十步大运逐步扫一遍**定一生上限。「破格…就是在大运中把坏的东西搞掉，格局成立」［ch2］。只查原局会把财富天花板判死 |
| 争合合到官杀，只取一种读法就下结论 | 「合制」原文两义：ch13 宽义「合也有制的意思」／ch14 窄义「力量悬殊、合而制去」。**争合状态下两说并存**——保守只算合动，进取接 ch6「制不尽的杀为大财」。**两读并陈＋标置信度**，别二选一［`09-zhiye.md` §三］ |
| 见「开库」就断发财 | 开完再问一句：**开出来的字谁接得住？**「先看墓库透什么、在做什么，就是表命主做功的方向（最重要）」［ch22］。五条自查见 `04-zuoyong.md` §九 |
| 把「空亡被大运填实」读成「由虚转实变好」 | **填实是凶**：「空就怕大运填实，**大运填实人即走**」［ch36］、「空墓填实的时候就是死亡大运的时候」［ch42］。按应期读，不按利好读 |
| 取象只把类象词典抄一遍，输出一串并列可能 | **跨柱两两相乘取交集**，交集才是落地答案［`02-quxiang.md` §九 第 8 条］ |
| 忘了副宫 | 副宫三成因：同五行异阴阳／正宫透干／正宫引出之字 |
| 一上来就出全盘长文 | 先走决策门，问看什么 |
| 通篇用「你」称呼盘的主人 | 来问的人不一定是本人。用**命主**（或用户给的称呼）；第二人称只留给读报告的人 |
| 主动断人寿元、牢狱、性功能 | 不问不说 |
