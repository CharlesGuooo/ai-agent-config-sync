# A 股约束清单

美股/期货导向的回测库不知道这些。**每一条都会让一个看起来能赚的规则在实盘里赚不到。**

## 交易机制

| 约束 | 后果 |
|---|---|
| **T+1** | 当日买入次日才能卖。**所有日内进出的规则直接不可执行**——威廉斯的 Oops、攻击日、5/30 分钟图形态全部倒在这一条上 |
| **涨跌停 ±10%（创业板/科创板 ±20%，ST ±5%）** | 两个后果：①涨停当日**买不进**（封单排队），跌停当日**卖不出**；②截断收益分布的两条尾巴 |
| **无散户做空**（现货） | 所有做空信号无法执行。威廉斯全书的卖出方向形态整体不迁移 |
| **停牌** | 持仓期间可能完全无法交易，持有期被动延长 |
| **除权除息** | 回测必须用前复权价（平台 `close` 已是前复权，`raw_close` 是原始价） |

### 涨跌停对回测的两处致命影响

**① 入场价不可得。** 一条规则若在涨停日入场，回测里能填成交价，实盘填不进去。
`SPEC-SETUP-03` 反包形态的 D1 就是涨停日——**但它的买点在 D3，不在 D1**，所以成立。
**任何以涨停日为入场日的规则，标 `不可执行`。**

**② 止损无法保证成交。** 威廉斯的头寸公式
`(账户 × 风险比例) / 单笔止损金额 = 数量` 有一个隐含前提：**单笔最大亏损 = 止损距离**。
连续跌停时这个前提**不成立**——你的实际亏损可以远大于止损距离。

> **这直接击穿了公式的分母。** 必须为连续跌停加尾部惩罚系数，否则系统性低估风险。

## 成本

| 项 | 值 |
|---|---|
| 佣金 | 万 3（双边） |
| 印花税 | 卖出千分之一（单边） |
| **往返合计** | **约 0.112%** |
| **费用地板** | **¥16,667**（单笔低于此，最低佣金 ¥5 使实际费率高于万 3） |

**回测的成本模型必须填 0.112% 往返。** 短线规则的单笔期望收益本来就小，
成本模型填 0 会让一批实际不赚钱的规则看起来能赚。

**费用地板与仓位联立**：`AGENT.md` O2 的 Band B 是 ¥5 万–20 万、3–5 仓。
配合威廉斯 3% 的风险比例，**必须验证单笔仓位不低于 ¥16,667**，否则费率失真。
资金 ¥5 万时 3 仓刚好触线——这是硬下限的由来。

## 数据前视

| 项 | 状态 |
|---|---|
| **同花顺概念/行业成分** | **只有当前快照，无历史版本** → 相关假设一律 `不可回测` |
| `mainline_history` | 基于上述成分表 → 同样污染 |
| 复权因子 | 需确认是否 PIT（历史复权因子会随后续除权变化） |
| 财务数据 | 需确认用的是公告日还是报告期。用报告期 = 前视 |

## 时间窗口与知识污染

平台数据窗口：**2025-09-03 → 2026-09-04**（244 个交易日）。

**评测者的知识截止是 2026-05。** 约九个月可能落在分布内——模型可能「记得」那段时间发生了什么。

- **只有约 80 个交易日是干净的**（截止之后），其中非修复日约 20 天
- **任何由 LLM 参与的历史评测只跑截止后窗口**
- 截止前的结果**按污染处理，不当作鼓励**

这条约束对纯代码回测不适用（代码没有知识截止），只对「让模型看历史数据做判断」的评测适用。

## 结果：威廉斯只有 6 条能原样过来

裁决全表在规格书 §13。能过来的：

1. 第一获利开盘价（bailout）—— **他最干净的一条**，次日开盘平仓天然满足 T+1
2. 时间离场（X 日不获利即走）
3. 双周期超买离场（N 进 / 2N 出）
4. 18 日均线连续两日穿越判趋势变化
5. `(账户 × 风险比例) / 止损额` 头寸公式（**须加跌停尾部惩罚**）
6. 2–4% 风险系数、按「连亏四笔」设计

其余要么半迁移（反向信号：留离场，弃反手），要么废弃（Oops、GSV、威尔差价、TDOM、凯利、
建仓日不设止损）。
