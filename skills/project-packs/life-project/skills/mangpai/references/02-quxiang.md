```
静态： ① 干支    ② 宫位    ③ 十神    ④ 神煞
动态： 合／化              刑／冲
```

## 一、共象原则

> 「八字中的某一字既有干支之象，又有宫位之象，还有十神之象，但它们如出现基本相同或相近的意思，那就可以确定该象了……**一般而言，只要有两类象表述同一种事物，即可确立该干支的象了。**故共象即为由两种及以上表示共同的东西。」

**例**：乙木日主，时上见丁火 —— 丁干之象有眼睛；时宫位也有眼睛之意；食神星有窍的意思，眼睛也是窍 → 此丁火可当眼睛看（三类象交叉在一点）。
**例**：辛日主见癸水 —— 癸有智慧的意思，食神有思想的意思，两者意思接近 → 此癸当思想、头脑看。

**实例**
```
乾：丁辛乙丁
    酉亥酉亥
```
> 「丁表目，时上也为目，故丁火食神为眼睛，支见亥，丁被克合坏，故三岁眼盲，不能视物。」

**共象还可依十神所在宫位区别含义**：
> 「如伤官食神可以表示小孩子，也可以表示女性之长辈。如它出现在年上，则表示女性之长辈；如它出现在时上，则表示小孩。」

```
乾：庚己丙庚
    戌卯戌寅
```
> 「此造食神戌在年上，表示女性之长辈，可以是母、外母或岳母，具体是哪一个则要细分，因戌与妻宫之戌相同，则表示与妻关系最近，那必是岳母。」

```
乾：辛丙辛丙
    卯申巳申
```
> 「此造巳申合，申上盖丙，巳与丙都是管理的意思，说明此人管理着这个『申』。『申』代表什么？从地支象上讲有机器、运转的意思；再看十神它是劫财，有机械、运作、炒作的意思——这样一定位，『申』就是运转着的机器，他是个管机器运转的人，这么一想，就明白他是个工人。实际正是。」

**时空八字**（以起八字的时间起盘断当下之事，段师用法）：
```
甲乙丙丁　（段师为乙日主，如无则纳禄比劫）
申亥辰酉
```
> 「丙辰桑拿的象，亥入墓。洗桑拿。丙为朱雀，生辰。辰为土为五，给人算命赚了五百元。」

```
丙乙庚乙　（问官司）
戌未戌酉
```
> 「丙为七杀，为法院。戌为朋友，年上戌为朋友的同学，伏吟到日支，法院向着你家（戌），乙酉年发生的经济官司，合财。一块地引起的三方官司。未戌酉为三方。把酉穿了，赢了官司。」
> **问事以起八字时间为准！**

## 二、合象原则

> 「八字中的某一字，通过干支、宫位、十神或神煞诸象中的两或两者以上的复合描述，得到一个象，为合象。合象往往两种不同的象，但**一方能定义另一方，或者一方能说明另一方**。」

**例**：丙火日主见戊戌时 —— 戌有建筑物之意，戊戌都是食神，食神有作品之意 → 建筑的作品，即建筑设计。

```
乾：壬癸丙戊
    子丑寅戌
```
> 「此造寅为印是工作，寅又是公门、机关，故为国家的单位，可断为公务员；戊戌一柱可表示建筑设计，又为食神，表示思想之义，合起来就是建筑设计。故他是个国家公务员，从事建筑设计。寅丑暗合有多种含义，这里壬子癸水多，丑又为湿土，表湿，寅主风，故他有风湿病，是因年轻时住地下室所致。」

### 合象的第二种情形：**相合双方可互用对方的象**
> 「天干五合与地支六合，相合的双方可以互用对方的象。相合如同夫妻结合成一家……**一方能定义另一方的性质与特征**。」（八字原局中有的合才能适用）

- 「**劫财合财**」→ 此财是「劫取而得到的财」
- 「**食神合印**」→ 印是学问，食神是思想 → 思想性的学问，即「学术」
- 「**伤官合印**」→ 伤官是技艺或艺术 → 「技能」「技艺」

```
乾：辛甲丁丙
    丑午丑午
```
> 「劫财丙合财，表示他取财的手段是用劫的方式，不是合法劳动所得；财在年上，是他人的财；又财库与禄相穿，表示是通过暗中较量而得财，实际是个赌徒。」

```
乾：戊己癸己
    申未巳未
```
> 「印星申合财星巳，申又是劫财之长生，申便可以描述成这样的象：它是一个机构（印星），又有很多的钱（合财星），且作风险性的运作（印中有劫财星）——实际此人是在操作股票，是一家证券公司老总。」

```
乾：庚乙癸庚　（孔祥熙）
    辰酉卯申
```
> 「满盘是金，再看卯申合，是金制卯木，印制食神。八字无财，卯是食神，是财的原神，可当钱的源头看。庚申金本来有金融的含义，合财的原神更确定无疑银行的含义。庚申是印，是权力的意思，所以从合象看他是一银行的大官员，实际是中央银行行长。」

```
乾：壬己癸乙
    寅酉酉卯
```
> 「时上乙卯食神代表什么？食神代表学生，而出现在时上，表示年龄非常之小……这个学生能在他命局中显现，又冲了夫妻宫，可见其关系非同一般。实际他找了一个小他二十多岁的小情人，还是他的学生。他是学校校长。」

### 阳制阴 / 阴制阳（公检法组合）

```
    未子丑寅
```

```
    申辰丑寅
```

## 三、化象原则

> 「化象是指八字中两个或两个以上的象，通过会合或生化的作用，转化成一个新的复合之象，这个新的象可以通过原来象推衍而得。**生、三合局、半合局都是一种转化。**」

| 组合 | 化出的象 |
|---|---|
| 阴木（卯）生火 | 丝线经加工 → 织物、布、服装（木为印一般做纺织／丝织；火为财一般搞服装生意） |
| 阳木生火 | 家具、家私、装璜 |
| 辰配子 | 化工、制药、提纯 |

```
坤：辛辛丙甲
    卯丑辰午
```
> 「卯木印星生日主之火，卯印代表工作，说明她的工作单位是纺织或刺绣厂，实际此人就在刺绣厂工作。」

```
坤：癸丁癸癸
    卯巳丑亥
```
> 「也是阴木生火，但她的火是财星，说明她是以此来取财的，断为搞服装生意。果是，她从事服装批发十几年了。」

```
乾：丁己庚庚
    酉酉子辰
```
> 「八字无财，以伤官子水当钱财。子辰合水局，辰为水之库，象泥土，从泥土中出水，有在浊中提纯的含义，所以断为搞化工提炼，实际正是。**化工是个现代行业，古代是没有的，所以『象』可以通过合理推理而得到。**」

```
乾：癸丙戊丙
    卯辰子辰
```
> 「这一个命是从事制药业，他是个职业经理人……也是子辰合之象。」

## 四、墓象原则

> 「墓是收藏、控制之意，墓的含义是**根据所墓之神来确定**的，也可能参合墓神本身的含义来确定。」
> 闲注：「七杀入了羊刃墓，表军队、军团；食伤库表示学校、工厂。」

```
乾：己辛戊甲
    卯未辰寅
```
> 「未为七杀之墓，就是权力中心的意思；而未土在八字中又是羊刃，羊刃又有军队的意思。**七杀入了羊刃墓，表军队**，说明他是个军官。实际是一少将。」（闲注：寅卯入未库，未入辰库，军队的师级）

```
乾：戊丙乙戊
    申辰丑寅
```
> 「坐支丑土是控制申金正官，申有军队、司法之象，他一定是军队、公安、检察院、法院之类的部门工作；再看丑有隐蔽之象，那就排除了检察院与法院的可能，这两类部门都公开的。实际他是公安机关的官员。」

```
乾：丁癸辛丁
    未卯卯酉
```
> 「财星墓于年支未，未土有建筑的含义，卯木这时可取建材之象。土木之组合可主地产或建筑业。实际他从事建筑施工。」（闲注：双卯入未库，土木结构，做土木工程的。禄冲财，很辛苦包工头！）

## 五、制象原则

> 「八字有合制，也有克制、冲制、刑制与穿制，这些制法都可以取其复合象，还推断一个人从事的行业。」

```
坤：壬庚丙辛
    寅戌午卯
```
> 「食神拱印，中学校长。木火主文，壬寅带象，中神在主位。」

```
乾：丁辛乙丁
    未亥巳丑
```
> 「丁为食神，学问。**丑是盲派。**」

```
乾：丁癸丙壬
    未丑子辰
```
> 「要点是丑未相冲，丑中癸水辛金制去未中丁火与乙木。丑是财库，财库制劫财与印库，劫财有炒作、运作等含义，可以推想，他取财的手段与方式是**资本运营**。为何不是搞投机生意呢？因为未这印库，**印主实体，有从事实业的含义**。」

```
乾：癸乙甲己　（岳飞）
    未卯子巳
```
> 「未羊刃之库，是表示集团军。这个集团军要干什么？来穿制日主坐下的子水，子水是印，表示权力，所以是表示他本人拥有军队控制权的意思。」

```
乾：乙壬甲甲
    未午子戌
```
> 「这个命造与岳飞有相似的地方，都是羊刃库穿印，掌军权的意思。但他命中有午未相合，午是伤官星，有头脑的意思，又是火，象文，故他是军队里的文官，不是武官。实际是军中一政委。」

```
乾：乙己丁庚
    未卯丑戌
```
> 「核心是丑戌相刑，这种刑是戌中之火制坏丑中之金的意思。丑是财库，所以是个发财的命。戌是建筑，卯戌合形成土木之象，故他是搞房产建筑业发财的。」

## 六、带象原则

> 「带象是干支象的应用原则，盲师派命理**将干与支统起来看，干就象一个人的头，而支就象一个人的肢体一样**。我们认识一个人，首先是看他的头象特点，其次才是身体特点。所以带象原则就是：**一柱干支，以干来统支之象，干决定支象之特点**；有时可取干支复合之象，也是以干为主导。」

| 组合 | 象 |
|---|---|
| **财带官帽** | 公家之财 |
| **官带财帽** | 管理财的官 |
| **印带官帽** | 权力 |
| **印带财帽** | 薪水，即上班领工资（印为单位，财来自印中之意）。财带印帽也是同样的意思 |

```
乾：壬庚辛乙
    子戌丑未
```
> 「此造从事建筑与地产业……因他取乙未之财，未有建筑的含义，加乙木透干，形成土木组合，就表示地产业。」

```
乾：癸甲戊癸
    巳子午亥
```
> 「戊癸合，从表像上看是取癸水之财。再看癸水是什么？它是从月令子水透出的（子与癸是通禄关系，可以相互代表对方）。再看子水，它带了七杀甲木之象，七杀为权力，甲子一柱就表示『管财的权力』。这样他合癸水，实际上是掌了财权。」（财带官帽，官统财了，表公家的财，由他来管理。实为县地矿局局长。）

```
乾：辛辛丙癸
    丑卯寅巳
```
> 「时上癸巳一柱，巳是禄，癸是官，表示自己头上带了个官。这个官星来自于哪里？癸与丑是半通禄的关系，丑是财库，可以肯定，**他是个管理财的官**。并不是所有丙日主癸巳时的人都有官位，此造还有一条，就是寅木印星坐支，是有单位之意。」

```
乾：甲癸戊丁
    午酉子巳
```
> 「戊癸合，日主合财，像是发财的命。但实际上此人是个做官的……细看，此造之禄是巳，巳上干是丁，丁通禄午，午上干是甲，甲是七杀星，代表权力——这样就等于午、丁都是权力的意思，**权力担在禄头上**，自然是表示他本人有权了。」

```
乾：辛庚丙丁
    卯子申酉
```
> 「首先看子水，它本是官星，但带干财，要当钱财看，不以官看（**官带财帽，官统财了，官当财看**，很大的财）……乙未运将子水穿制，所以发财……为何是开医药门诊？因未合局中卯，卯是印，是房子的意思，而带辛金财星，这个卯就是经营性房子；再看辛来自于时上酉，时为门面，开得还是门面房；再看未有药的含义……这个八字未土是伤官、食神，表示技能，所以是医药门诊店。」

## 七、借象原则

> 「八字中字，除了通过它们之间的各种相互作用可以换象、定象之外，还有一些重要的关系可以互通其象，称借象。其中有以下的两种关系可以互借其象：
> **① 天干通禄神的关系　② 同五行但阴阳不同的关系。**
> 比如天干是丙，地支是巳，丙巳是一家的，如果丙不太好定象，那就可以看巳怎么定象，巳的象一定下来，丙的象也就出来了。」

```
乾：庚己丁癸
    寅丑卯卯
```
> 「卯为妻宫，寅与卯同样的五行属性，那寅也为妻宫，这样庚金就是妻星。**八字中出现多个妻宫与妻星，就是有好几次婚姻。**此造第一个妻死，后再娶。」
> **「寅为副宫，如是卯木可能是副宫也可能不是。」**

```
乾：癸庚癸戊
    巳申丑午
```
> 「年上巳为父，则戊也为父。癸巳自合，巳申合，戊癸合，故癸与申均为母，说明父有四个老婆（丑中癸也一个）……以巳财星为父，巳是戊的禄神，其象一致，所以戊也为父。」

```
坤：癸甲甲丁　（孽情—夏老师断例）
    巳寅辰卯
```
> 「巳火有庚金，为丈夫，巳生辰，巳是丈夫了——借象了。丁火同样是丈夫。丁坐在子女宫，卯辰穿了，是别人的儿子。寅巳穿，丈夫也离过婚。**如果没有癸水，巳不能看丈夫。**癸是辰透出的。」

### 副宫的两种成因（原文注）
> 「夫妻宫副宫有两种情况：
> **（1）是从夫妻宫引出来的字，或夫妻宫是从某字中所引出，则该字为副宫。
> （2）与夫妻宫同五行的字。**」
> 另 [金口诀·ch23] 补充第三种：「**正宫透出天干之字为副宫。**」

## 八、吃西瓜理论 [取象·第七章]

> 「吃了西瓜肉，丢了西瓜皮，**富**。
> 吃了西瓜皮，丢了西瓜肉，**穷**。
> 皮肉一起吃的，也是**富**命。
> **吃西瓜条件：年干为西瓜皮，年支为西瓜肉。年柱是带象或见禄即是同象。时上的肉或皮被日主合到，就是被吃到的。**」

```
乾：乙乙庚乙
    卯卯辰酉
```
> 「庚金合时上的乙木财，等于是合了年月地支的卯，就好比此人吃了西瓜瓤一样，得到了财的实质，所以此人富。西瓜很多，看起来应该是特别富。皮肉一起吃的，也是富命。」

```
乾：癸乙丙辛　（王庆造）
    丑卯午卯
```

## 九、取象作业清单（把上面七条落成动作）

1. **定太极点**：先确定要断的那件事以谁为中心（婚姻以宫、职业以官财食印禄、六亲以宫定星）。
2. **四类静态象叠加**：该字的干支象 → 宫位象 → 十神象 → 神煞象，找出两类以上重合的 → **共象**成立。
3. **看它与谁发生了关系**：合／冲／穿／破／刑／绝／暗合 → 用 **合象／制象** 复合出新象。
4. **看它是否被生化**：三合、半合、相生 → **化象**。
5. **看它是否入库入墓**：入谁的墓库 → 该墓库以**所墓之神**的十神定名（羊刃库＝军营、食伤库＝学校寺庙、财库＝银行、官杀库＝权力中心）→ **墓象**。
6. **以干统支**：一柱之内，干决定支象的性质 → **带象**（财带官帽、官带财帽、印带官帽、印带财帽）。
7. **不好定象就借**：通禄关系、同五行异阴阳关系 → **借象**。
8. **跨柱相乘，取交集**：把做功涉及的几个字，各自的象**两两相乘找共同落点**——
   **交集才是可以落地的那个答案；并列清单不算完成取象。**
   - **反例（不合格）**：把做功那几个字的类象各抄一列，然后输出「可能是甲行业、乙行业、丙行业……」——
     几个候选之间**没有公共落点**，等于把词典誊了一遍，没有断。
   - **正例（合格）**：假设做功的三个字，类象分别含〔A1 A2 A3〕〔A2 B1 B2〕〔A2 C1〕——
     划掉不重合的，**三者共有的只剩 A2**，那么 A2 就是落点，再由 A2 展开成具体行业。
     **公共落点是算出来的，不是从某一个字的义项里挑一个顺眼的。**
   - **做法**：先按第 1 步定的太极点挑出 2–4 个真正在做功的字（**主位与宾位都要拿，别只看主位**），
     列出各自类象，**划掉不重合的，留下重合的**。重合度越高，落点越确定。
   - ⚠ **交集能收敛方向，收敛不到唯一答案。**类象词典对同一个字本来就给多个义项——
     同一个地支既可以是「泥、水库」，也可以是「田园、土产、机器、网络」，**取哪一支义项，结论天差地别**。
     所以断职业时**输出交集 ＋ 2–3 个候选 ＋ 请命主指认**，别单点断言——详见 `09-zhiye.md` §七 第 4 步。
     用一两条类象加已知背景（籍贯、学历）硬指一个行业，是**过拟合**，不是取象。
   - ⚠ **举例纪律**：本条（以及全参考库）的举例**一律用抽象符号或与 `evals/` 样本盘无关的字组**，
     **不得写入任何真实命例的四柱与答案**——否则该盘的盲测就变成开卷，参考库自己污染自己的评测。
9. **富贫粗判**：套吃西瓜理论。
