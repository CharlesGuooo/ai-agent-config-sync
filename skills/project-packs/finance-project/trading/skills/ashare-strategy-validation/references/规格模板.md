# 规格模板

一条经验法则填满这张表之后，才能进回测。**留空的字段就是你还没想清楚的地方。**

```yaml
id: H-00
一句话: "……"
出处: "书房⑤战法一 / 宝典招 32 / 威廉斯 ch.4"      # 必须可追溯
先验来源: 文本                                      # 文本 / 回测扫参。扫参出来的直接降级

标的池: "全 A，剔除 ST、上市 < 60 交易日、停牌"
入场:
  触发: "<可编码表达式，引用规格书规则 ID>"
  时点: "次日开盘 / 当日收盘"                        # T+1 下这一项决定可执行性
离场:
  获利: "<规则>"
  止损: "<规则>"
  最长持有: N 交易日                                 # 必填，没有它就是无限期持有
成本: 0.112%                                        # 往返，万3 + 印花税
零假设: "该形态出现后的次 H 日收益，与无条件基线无差异"
无条件基准:
  定义: "同标的池、同窗口，每个交易日都买、持有 H 日平"
  准确率_0: [待测]
  单笔均利_0: [待测]
最小样本: 截面 >= 300 事件（或时序 >= 12，并说明为什么走时序）
预登记终止日期: YYYY-MM-DD                           # 看数据之前写下
判死标准: "准确率或单笔均利未同时超过基线 → 判死"     # 看数据之前写下

状态: 待测 / 待数据 / 不可回测 / 不可执行 / 通过 / 判死
```

## 两条不能省的字段

**`预登记终止日期` 与 `判死标准` 必须在看数据之前写下。** 这是整张表里唯一真正防过拟合的部分——
其余字段只是把想法写清楚。先看数据再定标准，等于没有标准。

**`先验来源`**：出处是文本（书、访谈、实操记录）的假设，比回测扫参出来的可信得多，
因为它没有用同一份数据既生成又验证。`AGENT.md` O9 明确禁止拟合 `PHASE_EXPECTATIONS`，
理由正是这个。

## 唯一的完整样例：威廉斯波动性突破

选它做样例不是因为它能用——**它在 A 股不能用**——而是因为它把「一条规则怎么死」演示得最完整。

```yaml
id: H-DEMO
一句话: "开盘价 + k × 昨日真实波幅，突破即买"
出处: "威廉斯 ch.4 波动性突破（动能穿透）"
先验来源: 文本
标的池: "原书为 S&P500、美债、大豆等 24 小时期货"
入场:
  触发: "price > open + k * ATR(1)[-1]"
  时点: "日内触发即买"                    # ← 第一处死因
离场:
  获利: "第一获利开盘价"
  止损: "固定金额（原书 SP500 $2000–2500）"
  最长持有: 3
成本: 0.112%
状态: 不可执行
```

**三处死因，逐条对照 `A股约束.md`：**

1. **日内触发即买 + T+1** —— 当日买入次日才能卖，而这条规则的离场逻辑建立在快速进出上。
   T+1 把它的离场拿掉了。
2. **±10% 涨跌停截断右尾** —— 波动性突破的全部期望值来自突破之后的大幅延伸。
   涨停板恰好在最该延伸的那天封死。**它依赖的正是被截断的那部分分布。**
3. **固定金额止损不迁移** —— $2000 是美式期货合约面值下的数字，A 股现货没有对应物；
   且连续跌停时止损不保证成交。

**结论**：`不可执行`，进墓地。**不是因为它不好，是因为它为另一个市场设计。**

这也是本 skill 存在的理由：**统计方法是市场无关的，交易机制不是。**
`finance-project/quant-methods` 会告诉你这个策略是不是过拟合，
**不会告诉你它在 T+1 下根本没法执行。**

## 填表时最常见的三个漏项

1. **`最长持有` 留空** —— 于是回测变成无限期持有，收益全来自 beta
2. **`时点` 写成「触发时」** —— 在 T+1 + 涨跌停下，「触发时」经常是不可成交的时刻
3. **`无条件基准` 用 50%** —— 错。必须用同窗口的实测漂移率（威廉斯的 52% 就是这么来的）
