# 特殊题型：绝对词类 + 不可比较类

## 一、绝对词类题目

### 识别

题目含极端词：**most / best / only / never / always / key / essential**

- "退休是人生**最**幸福的时期"
- "减少犯罪的**关键**是更多警察巡逻"

### 核心策略：优先写不同意

- ✅ 绝对化意味着"总是/最"，一个反例就能推翻——好写
- ❌ 要证明"最/总是"需要穷尽所有情况——没法写

### 推荐结构：让步反驳

```
Introduction: 不同意
Body 1 (让步): 承认在某些情况下有道理
Body 2: 反驳——为什么绝对化不对（反例一）
Body 3: 反驳——反例二
Conclusion: 重申不同意
```

### ⚠️ 铁律：不要碰绝对词

用"为什么"转述时**避开绝对词本身**：

- 题目："退休是**最**幸福的时期"
- ❌ 错误转述：退休为什么不是"最"幸福的？（还是在证明"最"，没法穷尽比较）
- ✅ 正确转述：退休为什么**不幸福**？（找反例即可）

**原则：驳斥绝对化，不需要证明反向绝对化。**

### 案例：减少犯罪的关键是更多警察（Mixed 类）

问题1（同不同意）的 Brainstorming：

- **让步**：一定程度有用——震慑作用（deterrent effect），潜在罪犯怕被抓
- **反驳1**：不是所有犯罪都在街道上——入室抢劫（警察看不到）、网络犯罪/电信诈骗（跟街道巡逻无关）
- **反驳2**：震慑对某些人无效——心理有问题的人不怕坐牢；恐怖分子甚至希望警察聚集

问题2（其他方式）的思路：从犯罪原因入手——普法教育（很多人不知后果）、提高惩罚力度（醉驾入刑后立竿见影）、监控监管（CCTV + 网络监控）。

## Report 类（报告/问题解决型）开头模板

**第一段公式 = 改写原题 + 准确回答（点出归因/方向）**。

改写现象句 + 归因句（"X should be responsible for this" / "X are to blame"）：

- 题目：In many countries, schools have severe problems with student behaviour.
- 开头：Poor student behaviour seems to be an increasingly widespread problem, and I think that modern lifestyles should be responsible for this.

常用归因主语库：modern lifestyle / technological progress / sedentary lifestyle / peer pressure / media influence / the pursuit of a quality life / excessive consumption of unhealthy food / inability to resist various temptations

**注意**：Report 类开头就给出方向，主体段一问一段展开（见 question-types.md）。

## 二、不可比较类题目

### 识别

题目把**两个现实中都存在、都有价值的东西**强制比较：

- "种树比提供住房更重要"
- "政府不该花钱太空探索，应该花在环境上"

判断标准：这两个东西是同一领域吗？有客观标准判断谁更重要吗？写"A 比 B 重要"会不会很片面？

### 核心策略：写不同意 → 它们都很重要

**驳斥逻辑：题目说 A > B，我们证明 A = B。**

类比：长辈说"某个人比你厉害"——
- ❌ 错误驳斥："我不服，我比他厉害"（一样片面）
- ✅ 正确驳斥："他确实在某些方面突出，我也有我的长处"

### 为什么不能写同意

1. **太片面**：只能写 A 的好处，完全不能提 B
2. **忽略变量**：同一事物情况不同结论不同（种树 vs 住房：住房过剩的一线城市 vs 缺房的新西兰，结论相反）
3. **要穷尽所有因素**：考试中做不到

### 结构：两边论述

```
Introduction: 不同意（两者都很重要，不该二选一）
Body 1: A 为什么重要
Body 2: B 为什么重要
Conclusion: 两者都重要，应平衡发展
```

## 两类特殊题型对比

| | 绝对词类 | 不可比较类 |
|---|---------|-----------|
| 识别 | most/best/only/key | A vs B 强制比较 |
| 立场 | 优先不同意 | 不同意（都重要） |
| 结构 | 让步反驳 | 两边论述 |
| 驳斥方式 | 反例驳斥绝对化 | 证明 A = B |
| 铁律 | 转述时不碰绝对词 | 不要写成 A < B |
