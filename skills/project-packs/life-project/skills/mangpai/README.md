参考库中的口诀、断语、规则**逐字照录并标注章节出处**；原文自相矛盾处（如「四破」只列四组但案例中另用未申破；[取象] 说戊刃在未/巳而 [金口诀] 全书作戊刃在午）**两说并存并显式加注，不擅自和稀泥**。

## 排盘脚本

```bash
cd scripts
python paipan.py --date 1984-06-15 --time 14:30 --gender male
python paipan.py --date 1893-12-26 --time 08:00 --gender male --liunian 1949-1955
python paipan.py --sizhu "癸巳 甲子 丁酉 甲辰" --gender male --birth-year 1893
python paipan.py --date 1103-03-24 --time 10:00 --gender male --calendar julian
python paipan.py ... --json
```

**口径**（与工作区 `bazi-ziwei` 一致）：
- 年柱以立春为界，月柱以十二节为界，节气用 pyswisseph 实算
- 不做真太阳时经度校正；时区默认 +8（`--tz` 可调）
- 子时默认**晚子时**（23:00 后日柱进次日），`--zishi early` 可切
- 1582-10-15 之前按儒略历（`--calendar` 可强制）

**输出**：四柱（藏干十神 / 长生 / 自坐 / 主宾位）· 限运分段 · 盲派五神煞（禄神 / 羊刃分阴阳 / 墓库含十神库标签 / 盲派驿马年日双查 / 空亡年日双查）· 附加神煞（官符星 / 亡神 / 劫煞 / 破碎煞）· 干支虚实与互表（实干虚干 / 干支互通 / 自合柱 / 通禄互借）· 五行连片（连体连根候选）· 原局天干地支整柱作用全扫 · 大运逐步扫描 · 流年扫描。
