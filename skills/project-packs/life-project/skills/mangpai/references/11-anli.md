# 甲部 · 各专题推理范式（格式 → 断法 → 应期）

> 原始资料的案例讲解散在 198 处，本部把它们压缩成可执行的推理范式。**范式只是入口，落到具体八字仍须走做功与取象。**

## 1 格局 / 财富等级

| 格式 | 断法 | 应期 |
|---|---|---|
| 五行一党（木火／土金／金水…）＋两党对立且力量相当 | 清纯 → 大格局；体旺用旺 → 富贵 | 做功成立之运 |
| 体旺、用只有一点点 | 「用小体大」→ 无格局 | — |
| 身弱财重 | 穷命人 | 走财运更凶 |
| 财在墓库中做功 | **格局最高**；明面上劫财制财，层次低 | 刑冲开库之年发财 |
| 官统财 / 财统官 | 官杀当财看 → 巨富 | 制住统领（元神）之运 |
| 有明财、无官 | 一般不大 | — |
| 印星包局 / 财星包局 | 格局都不会太差 | 财星包局者克母 |
| 从旺格 | 只有两种五行最清纯；**大运来财就是外来的财，走这步运会被外来的财所害** | 见财运即凶 |

## 一、格局类

### 案例 1 · 虚实互表 · 换根 [ch12 例一]
**乾　辛酉　戊戌　癸亥　壬戌**
> 还原依据：四柱全部以完整干支形式见于正文（「时柱壬戌是虚干」「原局癸亥」「辛酉一柱」「戊戌虽然是实干」）＋「癸水生在戌月」。V1=4 V2✓ V3✓

- **格局**：金水一党。戌土周边都是水，可以把它当金看（戌土生了酉金、辛金）。天干透一个土会被同化。传统派讲要用金水，**用金水会倒霉死**。
- **虚实**：时柱壬戌是虚干。「原局癸虽然合了官，但原局没有明财，**没有明财的官就是虚官**，虚官也就代表没有财源的官——他的公司经营的非常辛苦，打不开路子。」
- **换根断婚姻**：「原局癸亥，亥就是婚姻宫，也就是家。**换根就是庚子年**：子和癸是同性，与婚姻宫同五行但不同阴阳之字就是**副宫**，子在原局是没有的，所以在庚子这一年就分居了。」
- **己亥年**：己亥自合，己土是癸水的杀，亥水是他的体，己土在原局是没有的，**他的体伏吟到流年，流年合了一个杀**——这一年在工作中遇到了一个姑娘，命主出轨。
- **要点**：「弄清自己的体，有没有到外面合到自己的官。**不要以为财就是女人，也不要以为官就是男人**——官也可以变成财。」

### 案例 2 · 土金伤官·格局最差 [ch4 例一]
**乾　己酉　甲戌　戊午　乙卯**（饭都吃不起的小保安）
> 还原依据：「戊土生在戌月身旺」（V2+V3）＋讲解点名的**酉戌穿、午酉破、甲己合**三条原局关系全部命中。

- 火土一党，三土一火，戊土生在戌月身旺，**身旺要用伤官**。
- **戊土坐午为刃，刃是需要制掉的**——「拿刀拿枪管人，坐下的刃，就是当保安的命」。
- 病在：**酉戌穿、午酉破、卯酉冲，都意在去掉这个伤官**；天干透官降分；**甲己合也带着酉金入了戌墓**（戌是火库、金墓），伤官入墓 → 脑子不好使，读书读不进去，一辈子苦力。
- 「**食伤入墓，就是脑子不清爽的。**天干相合地支穿，也代表他心理上是有残疾的。」
- 40 多岁未婚：午火进了墓库，比劫星合了婚姻宫。

### 案例 3 · 食神制杀 · 先从政后经商 [ch7 例一]
**乾　壬寅　甲辰　壬午　壬寅**（厅级以上干部，退休后经商）
> 还原依据：三柱以完整干支见于正文；讲解「以甲辰这一柱为中心」「年干的壬水比肩在宾位」「壬寅也就是命主要管的东西」「午自合」逐一对应。

- 水木一党制火土。**辰土是杀库，壬、寅都从辰中出**——「辰土里出来的这些水木，都是我的体」。
- **食神制杀**：壬生甲，甲制辰杀。杀在宾位、月令 → 官比较大；但**杀没有透 → 只是有钱，不显贵**（食神制杀里面，杀透为贵）。
- 取象：「壬寅是辰出来的……甲制了辰，**他要管理的都是这些很有钱人的钱** → 财政厅，管财的人。」辰在巽宫（四维宫）→ **官多为副职**。
- **两段人生**：辰辰自刑，辰库开着 → 从政；**己酉大运甲己合＋辰酉合（天合地合）→ 杀库闭库 → 食神不再制杀 → 47 岁后经商创业**。

## 二、婚姻类

### 案例 4 · 未申破克死夫 [ch27 例一]
**坤　丁未　戊申　丙辰　癸巳**
> 还原依据：讲解点名的原局关系 **未申破、巳申合、癸巳自合、戊癸合** 四条全部命中（4/4）。

- 火土一党（丙戊同项，丙戊都连巳），**未土是印库、比劫库，未出巳、出丁、出丙**——「未土和所有的地支发生了关系」。
- **癸水正官在时柱**（子女宫），戊癸合＋癸巳自合＋巳申合 → 官星受伤极重。
- **申是癸水的元神**，未申破 → **伤到官星的元神 → 克死夫**（「年柱劫财坐伤官，头婚嫁个短命郎」的先决条件全部符合）。
- 断健康：「癸水主淋巴免疫系统，癸巳自合带了巳的像，巳在内主血液、心脏……**火土两旺的时候，这样的人免疫系统会出现癌症**。」
- **应期**：21 岁庚戌运丁卯年结婚；**24 岁庚午年**——未戌刑开了坟包，庚午年巳午未三合、庚金升天又虚透，夫亡。辛未年母亲亡（戊申一柱为母星，未申破）。

### 案例 5 · 宫星同字 · 星临墓绝 [ch30 例一]
**坤　癸丑　戊午　戊寅　己未**
> 还原依据：讲解点名的 **丑午穿、丑未刑（丑未冲）、寅丑暗合、戊癸合** 全部命中。

- 火土一党制金水，用小体大 → **没有什么格局**，普通人（农民）。
- **寅木既是宫也是星（宫星同字，最凶）**；寅从未中出 → 夫星在墓中；「**寅见墓以后就不能再见死、绝了**」。
- 20 岁庚申大运：**寅申冲**——寅就是甲，甲的绝地就是申，「宫星同字，这种直接的冲非常凶……**家里住的人天天在家里不出去，就是人背着这个房子在跑，当碰到申金的时候没有可躲避的地方**」。
- **应期**：寅亥年结婚生子；**戊申年**两申冲一寅（两个绝地）＋**戊癸合＝关财门** → 死第一任丈夫。33 岁辛酉大运甲申年，甲木虚透流年坐绝，寅酉绝＋寅申冲＋午酉破 → 死第二任丈夫。

### 案例 6 · 婚姻宫入墓 · 独身（同一盘在书中出现两次）[ch24 例一 ＝ ch25 例五]
**乾　癸酉　己未　乙卯　壬午**（30 多岁未婚）
> 还原依据：ch25 例五处「壬午」以完整干支见于正文（V1）；十神标签（偏印／偏财／日／正印）对**日主乙**唯一解出癸、己、壬（V4）；**V6 双中**——癸年未月起己 ✓、乙日午时起壬 ✓。
> ⚠**修正记录**：ch24 例一处的讲解被 OCR 成「**己**土生在未月」，据此自动还原会得出日主己，但那样月干、时干**同时**违反起月法与起时法。回查同段「**乙**走到未是养的」（乙逆行确在未为养）、「婚姻宫是**禄星**」（乙禄在卯）、「**乙木克己土**」，可断日主为**乙**，「己土生在未月」系「乙木生在未月」之误录。改用乙后 V6 双中，且与 ch25 例五同盘互证。

- **婚姻宫卯就是乙的禄星**。「乙走到未是养的，像这样的人肯定要用卯木禄星来撑着他。**但是卯木就是婚姻宫，婚姻宫到了未墓里面，所以这个小伙至今没有婚姻**」（卯入未墓）。
- 财旺杀旺：己未都是财，酉是杀。一心求财。

### 案例 23 · 毛主席 [ch1 / ch38 例九]

### 案例 24 · 某盲派大师本人 [ch49]

- **亥未拱合**——亥为学术、食神为学生 → **用印制食神，就是用学术治理学员**；**巳亥冲，印统了杀** → 搞学术能得大名气。**辛金虚透 → 虚透的七杀为名气**（「所以很多名人七杀都是虚透的」）。
- 原局**食神制杀、财来去印**。
- **取象**：「火主文化，**丑土主玄学，丁丑主盲派**；丁为眼睛，丑去晦丁火，**主盲派看不见**。」

  - 申运壬午年：**壬午自合就是反局**（原局财去印，流年印坏食神，坏了财的原神），也是**原局丑午穿的应期**；丁为食神＝学员＝学术成果，**丁通禄于午被穿 → 必发生与学生和学术的不顺之事；丁主南，应在南方** → 当年学术成果被一学员在广州盗卖，两徒弟参与被开除。
  - 申运乙酉年：**巳酉丑合杀局，反局**，杀主小人恶人 → 学生自诩盲派宗师在北京开班；乙酉年眼睛不好。
  - 丁未运（07 年换运）：**未冲开丑，丁食神到，食神制杀的应期** → 解开玄学之谜，将盲派命理理通。癸未年冲出门户，定居海外。

### 案例 25 · 丁亥大运身首异处 [ch50 例五]
