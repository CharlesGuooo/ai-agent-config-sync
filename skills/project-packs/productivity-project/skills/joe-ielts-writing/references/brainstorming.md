# Brainstorming：具象化 + 情景化

## 核心病因：中式思维从笼统到笼统

```
题目：学体育要不要学数理化？
中式想法：没用 → 太难 → 占时间 → 推不下去
```

**延展不下去只有一个原因：方向依然太笼统。**

"体育艺术"还笼统，"数理化生"还笼统，"太难了"还是感觉。
"学绘画的学生学力学受力分析"——这才具体，才能展开。

## 观点 ≠ 论证

| 写法 | 内容 | 分数 |
|------|------|------|
| 中式 | 打游戏可以放松。学习太累，打游戏可以放松身心。 | 5.5 |
| 雅思 | 打游戏可以放松。学习压力大时，打游戏能让大脑从紧张状态暂时抽离，降低皮质醇水平，恢复精力。 | 7.0+ |

雅思大作文：**观点不重要，论证最重要。**

## 方法一：具象化题目 ⭐

把题目中抽象、笼统的名词/名词短语具体化，再基于具体内容推理。

### 操作步骤

1. 圈出题目中笼统抽象的名词
2. 逐一往下拆，拆到具体可操作的内容
3. 基于具象内容推理

### 演示

题目：All university students should be required to study science courses, regardless of their field of study.

**具象化"科学课"**：
```
科学课 → 数理化生
数学：运算规则、几何、统计
物理：自然现象、受力分析、电流电压、磁场
化学：物质反应、方程式、微观结构
生物：生态、进化、人体结构
```

**具象化"专业"**：
```
艺术类：绘画 → 绘画技巧、色彩原理、构图、绘画史、审美鉴赏
体育类：田径 → 训练、体能、技巧
```

**基于具象推理**：
- 不同意（没用）：绘画技巧/色彩/构图 vs 受力分析/方程式——零交集，用不上
- 同意（学科交叉）：装置艺术展→声光电互动→需要理工科；达芬奇→几何光影；运动员→肌肉组织群（生物）、营养搭配（化学）

## 方法二：情景化题目 ⭐

把题目映射到生活中，设身处地想。可以映射到自己，也可以映射到别人。

### 操作步骤

1. 设定具体场景，映射到具体的人
2. 不断追问"为什么"，直到具体化
3. 概括成论点

### 演示

同上的"科学课"题，论证"太难"：

```
场景：某艺术学院要求绘画系学生上物理课，他们什么反应？

追问：数理化生难 → 哪个最难？→ 物理 → 物理哪里难？
→ 受力分析（各种力同时作用，看不见）
→ 电流电压（看不见流动）
→ 磁场（想象出来的）

概括：科学课难在抽象概念、符号系统、理想模型，
而艺术体育生擅长具体操作、不擅长抽象思维。
```

真实课堂案例：学绘画的学生问"1/2 中间那个横杠是啥？"——这就是抽象能力差距的具象证据。

### 演示 2（拆不动的抽象词 → 情景化）

题目：Tourism is always a force for good which enables people of different countries to understand each other. To what extent do you agree or disagree?

"tourism" 太抽象、拆不动（拆下去还是笼统）→ 情景化，映射自己的真实经历：

```
想象自己上次旅游——去哪儿玩了？具体干了什么？
→ 看景点、拍照、吃饭、住酒店、买纪念品……
→ 复盘整个过程：几乎没跟当地人有实质交流
→ 概括成论点：旅游很难谈得上让不同国家的人理解彼此（正面反驳题目主张）
```

## 两个方法怎么用

| | 具象化 | 情景化 |
|---|--------|--------|
| 原理 | 拆抽象名词 | 映射生活场景 |
| 适用 | 题目有明显抽象名词 | 任何题目，尤其抽象名词拆不动时 |
| 优势 | 逻辑层次分明 | 有画面感，容易想到 |

- **选择标准：看题目里的抽象名词好不好拆**
  - 一眼能拆成具体内容的 → 具象化（科技 → 自动化机器；科学课 → 数理化生）
  - 太抽象拆不动的 → 情景化（tourism 是典型：本身是个活动大类，拆下去还是笼统）
- 情景化的操作：映射到**自己的真实经历**——想象自己去哪儿玩了、具体干了什么；经历天然好延展，论点从经历里长出来
- 两者可以结合
- ⚠️ 每道题先明说选哪个工具、为什么——不要默认直奔具象化
- 论据内容是从生活场景想出来的，就要把"设身处地"那一步亮给学生看（"想象你自己上次旅游……"）——让学生看到这是情景化在起作用

## 教学演示规矩：给过程，不给成品

学生要学的不是这条论据，是"怎么想出来"。带学生 brainstorm 时：

- **入口**：审题定完结构和每段方向后，先问学生"你有想法吗？"——有想法就顺着他的想法带推导；没有再讲方法论，让他用方法自己推
- 把每一步追问摆出来："太笼统 → 具体指什么？→ 为什么？"——最好让学生自己回答其中几步
- 不要一次性抛出完整因果链成品，也不要给带素材的选项（"建筑工人还是幼儿园老师" = 替学生做完了 brainstorm）——学生拿到成品，下次换题还是不会
- 成品链在学生推完之后给出作对照；且推导收口时必须有一个**完整中文段落**落地（书面语域，见 body-paragraph.md）——学生没看到一个完整落地的东西，就不算教完。谁来组装按 SKILL.md「两种教学模式」：引导模式先请学生自己组装，AI 点评后再问要不要看示范；示范模式由 AI 组装

## 反模式（学生常见错误）

- ❌ 观点堆砌：第一、第二、第三，每个一句，无论证
- ❌ 感觉推理：我觉得、我认为，无证据
- ❌ 空洞说教：大道理、假大空
- ❌ 脱离事实：编造不存在的论据

## 没想法怎么办

如果是**完全没想法**（脑子里没货）：这是输入问题，不是方法问题。国内不考这类社会议题，学生第一次被问"犯罪/环境/政府责任"自然没想法。药方：按话题积累素材、大量阅读相关话题文章。高质量输出必须先有高质量输入。

**常考话题清单**（积累素材按此对号入座，共 24 个方向）：
Advertising（广告）、Animal rights（动物权益）、Cities（城市）、Crime（犯罪）、Education（教育）、Environment（环境）、Family（家庭）、Gender（性别）、Genetic Engineering（基因工程）、Global issues（全球问题）、Government and Society（政府与社会）、Guns and Weapons（枪支）、Health（健康）、Housing and Architecture（住房建筑）、Language（语言）、Money（金钱）、Personality（性格）、Sport and Leisure（运动休闲）、Television/Internet/Phones（电视网络手机）、Tourism and Travel（旅游）、Traditional vs Modern（传统与现代）、Transport（交通）、Water（水资源）、Work（工作）

**题库检索法（Joe 的课堂方法）**：对完全没想法的学生，从 [question-bank.md](question-bank.md)（527 道真题，按话题分类）检索该话题的 2-3 道真实考题，用三件套给学生出中文论证素材。雅思基本不出新题、多从题库抽原题或稍作改动——学生考场上碰到原题的情况真实存在，可当作动力话术。

**⚠️ 素材书陷阱（Joe 的明确态度）**：市面上的话题素材书（如 ielts-simon 的 Ideas for IELTS topics）**只列笼统观点、不给论据**——学生直接参考只能写出假大空的东西（见"反模式"），不如不用。素材必须按"**观点 + 论据 + 具象化**"三件套积累：一个观点，配一条"为什么"的因果链，配 1-2 个具体例子/场景。缺了后两件的素材，上了考场照样推不开。学生拿着素材书观点来问时，先警告这个风险，再用上面的具象化/情景化方法带他给观点补论据。
