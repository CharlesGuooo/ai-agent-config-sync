## 一、会让你判反的四个字段

### `up_ratio` —— 是涨跌家数**比**，不是上涨**占比**

实测某日 `up_ratio = 0.8127`，同日 `up_count = 2322`、`down_count = 2857`。
`2322 / 2857 = 0.8127`——它是涨家数除以跌家数。

看着像「81% 的股票上涨」，**实际当日只有 44.8% 上涨，是个下跌日**。
这是全表最容易被读反的字段，且读反的方向恰好是把弱市读成强市。

**要「上涨占比」时，自己算 `up_count / (up_count + down_count)`。**

### `avg_turnover` —— 是成交额（元），不是换手率

实测值量级在 `3.8e8`（约 3.8 亿元）。**书房所有「换手率」判据都不能用它。**
个股换手率用 `turnover_rate`（`kline_daily_enriched`）。

市场层想看情绪量能，用 `total_amount` 或 `avg_turnover` 的**自身历史分位**，
不要与个股换手率放在一句话里比较。

### 量纲混用 —— 同一张表两种标度

| 0–1 小数 | 0–100 百分数 |
|---|---|
| `seal_rate` `promo_rate` `above_ma20_pct` `up_ratio` `index_pct` `avg_pct` `median_pct` `ladder_completeness` | `strong_up_pct` `strong_down_pct` |

日线侧 `change_pct` 也是小数（`0.05` = 5%）。**跨字段比较前先对齐标度。**

### `median_pct` —— 死指标，不要预测它

`observer/scoreboard.py` 的 `METRICS["median_pct"]["eps"] = 0.5` 是按百分数写的，
但落盘值是小数，日变化中位数只有 `0.0118`。`direction()` 不做缩放，于是 `abs(d) <= 0.5` 永远成立。

**实测 243/243 天恒为「持平」。** 预测它 = 永远无法被判定命中或错误。
修好之前，`median_pct` 不得出现在研判层输出的 `metric` 字段里。

### 附：`phase` 的时间属性

`phase` 是 EMA(α=1/3) + 两日确认的标签，**实测平均段长 12.20 天**（弱档否决后 20 段 / 244 天；
raw 口径 18 段 / 13.56 天）。**它是同步/滞后指标，不是领先指标**，段长越长滞后越严重。
把它当次日预测读，就是 `mean(edge) = −0.134` 已经抓到的那个陷阱。

## 二、情绪阶段的真实分布

完整分布表在规格书 §1.2（244 天实测，唯一权威）。这里只记对判读有后果的三条：

1. `AGENT.md` 记的「repair 占 ~74%」**实测 84.8%（raw）/ 86.1%（评分口径）**。非修复日全年只有 37 天。
2. **`climax` 一次都没出现过。** 针对高潮期的任何判断当前不可检验，标 `待数据`。
3. `MIN_BASELINE_SAMPLES = 12` 之下，只有 `ignite`(14) 与 `rally`(13) 勉强够样本；
   `ebb`(7)、`ice`(3) **永远出不了基准率**。

**所以：规则要在个股-日截面上检验（数千事件），不要在 regime-日上检验（37 个）。**

## 三、记分牌的指标菜单

研判层输出的 `metric` 必须取自这 7 项（定义在 `observer/scoreboard.py` 的 `METRICS`，**代码为准**）：

| metric | 中文 | eps | 实测可用性 |
|---|---|---:|---|
| `limit_up` | 涨停家数 | 5.0 | 正常 |
| `max_consecutive` | 最高连板高度 | 0.5 | 正常 |
| `strong_down_pct` | 大跌家数占比 | 2.0 | 正常 |
| `seal_rate` | 封板率 | 0.05 | 偏钝（88/243 持平） |
| `promo_rate` | 晋级率 | 0.05 | 偏钝（116/243 持平） |
| `ge2_count` | 二板以上家数 | 3.0 | 偏钝（125/243 持平） |
| `median_pct` | 全市场中位涨幅 | 0.5 | **不可用（243/243 持平）** |

方向取自 `{上升, 下降, 持平}`。判定式：`abs(今日 − 昨日) <= eps` 即「持平」。

## 四、八项数据缺口

按对低吸/反包策略的重要性排序。完整版在规格书 §2.2。

| # | 缺什么 | 挡住什么 | 数据源 | 优先级 |
|---|---|---|---|---|
| G1 | **分时/分钟 K** | 书房体系约 40%：分时均价线、10:30 前翻红、盘中开合、小周期背离 | eltdx / TickFlow Pro | **最高** |
| G2 | 涨停池 / 炸板池 | 复盘第 1 步的涨停全集 | 东财（有风控） | 高（可用 `consecutive_limit_ups` 降级） |
| G3 | 封单量 / 封流比 / 首末封板时间 | 龙头判定的行业口径、烂板识别 | 逐笔或快照 | 高 |
| G4 | 集合竞价过程 | 竞价量比、高开确认 | eltdx `auction_data()` | 中 |
| G5 | 热度榜 / 人气排名 | 复盘第 1 步的候选池 | 东财人气榜 | 中（可用成交额降级） |
| G6 | 新闻 / 公告 / 涨停原因 | **归因与否决闸门的全部文本证据** | 东财 reportapi | 中 |
| G7 | `signal_ma30_breakout/breakdown`、`ma18` | 30 日生命线状态机、威廉斯趋势判定 | **零成本自建** | **立刻做** |
| G8 | 资金流 / 北向 | 主力动向类判据 | HKSCC / 沪深股通 | 低 |

**G7 是最便宜的一项**：书房整套体系挂在 30 日均线上，平台有 `ma30` 的值，却唯独没有它的突破信号
（只有 ma5/ma10/ma20）。纯派生，无需新数据源。
