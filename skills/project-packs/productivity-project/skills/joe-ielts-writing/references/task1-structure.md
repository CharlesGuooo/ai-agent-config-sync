# Task 1 结构与决策流程

## 最高原则：Report，不是 Comment

题目要求永远是 "Summarise the information by **selecting and reporting** the main features, and make comparisons where relevant."

- ✅ 只报告数据：客观描述趋势和特征、选关键信息、恰当连接
- ❌ 不评论数据：不解释为什么变化、不表达观点（I think）、不用情感词（surprisingly）、不纠数据的事实错误

**评分锚点**：Band 8 = presents, highlights and illustrates key features **clearly and appropriately**；Band 6 = details may be irrelevant, inappropriate or **inaccurate**（数据不准直接 6）。

## 总决策流程（拿到任何图，30 秒走完）

**第一步永远先认图型——不同图型的第一步不一样，顺序不能乱：**

```
多饼图（≥2 个饼）→ 专用四步（顺序固定）：
   ① 给元素排大小（以第一张图/第一年为准，决定主体段写作顺序）
   ② 判断动/静态：有时间变化 → 每个元素从第一年连到最后年 = 一根线，转线图处理
                   无时间变化 → 同一元素在不同类别中比较
   ③ 分段（2-3 段、字数均衡——详见下方"Body：分段四原则"）
   ④ 按动态或静态方式写作

柱图/表格 → ① 看有无时间变化（动态→转线图；静态→元素比比较）
            ② 数元素比 = 柱图横纵轴比 = 表格行列比
               ├─ 一方 ≤2 元素（如 5:2）→ 按少的一方对比写（如男女逐学历对比）
               └─ 双方都 >2（如 6:3）→ 按少的一方分类写
            ③ 分段 2 段或 3 段

线图/单饼 → 直接进入段落结构（下）
```

**⚠️ 最常见教学事故**：把多饼图当普通图"先判动静态"，跳过排大小——讲义明确顺序是**排大小在前**（排大小决定写作顺序，动静态决定写法，两码事）。带学生走流程时，多饼图必须从第①步开始。

**静态图只能写**：最大、最小、相似、相等、倍数、多多少/少多少。**静态图绝不能写**上升、下降、稳定、波动、趋势——这是最常见死法。

## 段落结构：Intro（1 句）→ Overview（2 句）→ Body（2-3 段）

**小作文没有总结段**（那是大作文的）。Overview 是报告客观主要趋势/差异，不是主观结论。

### Introduction：只写一句话

改写题目背景句（**只改写背景段，要求段不用管**）：

> The [chart type] illustrates the comparison [and variation] of [主题] in [单位] in [地点] during the period between A and B / in A, B and C respectively.

填空规则：
- chart type：table / column (bar) chart / line graph / pie chart
- **and variation**：只有有时间变化（≥2 年）才加；无时间变化删掉
- 主题：题目 "shows" 后面的内容，去掉时间、地点、单位
- 单位：题目是 % 可换 proportion/percentage；不确定就删掉
- 时间：三年以上 → during the period between A and B；两三年 → in A, B and C respectively（只有 1 年不写 respectively）；含未来预测 → since A until the present and the projection to B

保底价值：即使只写出 Introduction，至少 3 分。

### Overview：只写两句话

1. 第一句必须以 **Overall,** 开头（段间衔接，CC 分）
2. 一句写**趋势** + 一句写 **Difference**（比大小，报告最明显的特征）
   - 无趋势的静态图 → 写两个 Difference：**把柱图/表格当表格看，行与行比一句 + 列与列比一句**（两个轴各比一次——如商品跟商品比、国家跟国家比；语料例题：电生产消耗图 = 国家之间比一句 + 生产与消耗比一句）。❌ 不写"整体看差距不大"这类笼统观察——不是体系内的维度
3. **不放具体数据**——概述写笼统内容，数据全部留给 Body

**评分锚点**：Band 7 = clear overview of main trends, **differences** or stages；Band 5 = recounts detail mechanically with **no clear overview**。漏写 Overview 直接压到 5。

### Body：分段四原则

1. **Grouping**：similar data / similar traces / same category 放一段
2. **字数均衡**：分 2 段每段 3-4 句；分 3 段每段 2-3 句
3. **交点（Crossover）**：A 超过 B，**先写 B**——先把被超的写完，写到超越者时"分别超过……"才有铺垫（CC 分）
4. **段内顺序**：从大往小写

⚠️ 线图分段就是这四条原则，别拿别处的速记当答案。线图**一根线单独成段完全合法**：只有两根线时只能一根一段；三根线也必有一根单独一段，不可避免。"避免单独一段"只存在于饼表柱静态语境（单元素撑不起一段），不适用于线图。

**数据挑选五要素**（每根线必查）：起点 → 趋势 → 交点（A 超 B）→ 极值点 → 终点。只报五要素像流水账（6 分）；要 7 分必须**切线**套高级模板（见 task1-templates.md）。

**线图 Body 段决策链**：分几段定了 → 每段句数就定了（原则 2：分 2 段每段 3-4 句，分 3 段每段 2-3 句）→ 句数决定**切几下**：2 句切 1 下、3 句切 2 下、4 句切 3 下（切几下 = 句数 − 1）→ 每处切线套一个高级模板 → 写完检查两样：**时态**（见下）和**句间连接**（只有两种：数据逻辑 + 时间逻辑，连接词见 task1-templates.md）。

## 时态判断

- 过去到现在 → 现在完成时
- 现在到未来 → be predicted/expected/projected to（用完了再用 will）
- 全部在过去 → 过去时；只有 V 字模板的前半句用过去完成时（had increased before decreasing）

## 避免重复的四个维度

主语（proportion → the figure → this quantity）、句型（四种轮换）、动词、时间表达——能不重复就不重复。

## 考试时间分配（共 20 分钟）

Body 12-13 分钟（最重要）→ Intro 2 分钟 → Overview 2-3 分钟 → 检查 2-3 分钟。目标 150-200 词。
