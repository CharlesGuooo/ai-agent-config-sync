# 量价与换手：读法

阈值在规格书。这里只讲**同一个数字在不同位置意味着什么**。

## 换手率是分歧/锁筹的计量器

书房整套体系把 `turnover_rate` 当情绪温度计用。核心洞察：**同样是涨停，换手率决定它是好消息还是坏消息。**

| 读数 | 位置 | 含义 | 规则 |
|---|---|---|---|
| 低换手 + 涨停 | 任何位置 | **锁筹**：筹码不愿出手，惜售 | `SPEC-VOL-02` |
| 中等换手 + 连板 | 连板过程中 | **健康**：正常换手，上涨可持续 | `SPEC-VOL-01` |
| 高换手 + 收阳 | 连板 ≥ 3 之后 | **分歧**：多空在高位充分交换筹码，前期获利资金在出逃 | `SPEC-VOL-03` |
| 极高换手 + 烂板 | 连板 ≥ 5 之后 | **末强确认**：筹码极度松动 | `SPEC-VOL-04` |

关键在于**位置**，不在于数字本身。同一个换手率数值，在初强启动日是好事，在第六个板是危险信号。
这是书房「物极必反」的全部内容：*惯性上涨中保持警惕，利用换手率判断市场情绪的顶点，确保自己能顺利下车。*

**书房给的两个对照场景**（`SPEC-VOL-02` / `SPEC-VOL-03` 的出处）：
连涨五天、每日换手 5–8% 是健康的；第六天若换手暴增而涨幅收窄、反复开板，是出货嫌疑；
第六天若缩量一字板、换手仅 3%，则续涨概率大得多。**同一天、同样收阳，结论相反。**

书房自己加了限定，值得原样保留：**即使是缩量涨停，在连续上涨多日后也随时可能迎来获利盘抛压。**
所以锁筹读数**不单独构成买入依据**。

## 量价关系：位置才是变量

宝典招 94–100 用 量↑↓平 × 价↑↓平 排了一张矩阵（书中实际只覆盖 9 格中的 7 格，缺「量平价平」与「量缩价升」）。
提取后的真实结论是：

> **判定信号真伪的实际变量是「位置」，不是量价组合本身。** 同一组合在不同位置，书中给出相反结论。

例如「量增价跌」：上涨初期被解释为主力震仓洗盘（持股），上涨途中被解释为可能深幅调整。
书里唯一给出的硬过滤器是 `ma60`——回调不破 60 日均线且该线始终向上，才继续看多。

**读法**：不要把量价组合当信号用。把它当**描述语言**，配合位置（低位/上升途中/高位/下跌末期）与
一条可测的过滤器（`ma60` 或 `SPEC-STRUCT-08` 的量能不对称）一起说。

## 三段量能节奏

书房称这是三大战法的共通精髓：**放量 → 缩量 → 再放量**（`SPEC-VOL-11`）。

- 一浪放量：资金进场
- 二浪缩量：抛压枯竭，这是**必须的**——不缩量说明没洗干净
- 三浪更大量：真突破

*「没有量能配合的加油是假突破。」* 三段里缺任何一段，形态不成立。

## 地量 / 天量：不要用这两个词

宝典全章使用数十次，**从未给出定义**——无基准、无回看窗口、无倍数。全章唯一明确的量化倍数是
招 85 的「3 倍以上」（`SPEC-VOL-15`），而它的基准窗口天数同样未给。

平台侧可用的量能基准只有三个，全部是显式的：

- `vol_ma5` / `vol_ma10` — 5 日、10 日均量线
- `vol_ratio_5d` — 量比。**⚠️ 其定义须与行业口径核对，未核对前 `SPEC-VOL-10` 的 1.5 阈值不可用**
- `signal_volume_surge` — 平台已算的放量布尔量

**说「`volume` 是 `vol_ma5` 的 3.2 倍」，不要说「出现天量」。**

## 与情绪阶段的关系

个股换手率（`turnover_rate`）与市场层的 `avg_turnover` **不是一回事**——后者是成交额（元），不是率。
市场情绪的量能观察用 `total_amount` 与 `avg_turnover` 的**自身历史分位**，不要与个股换手率混谈。
