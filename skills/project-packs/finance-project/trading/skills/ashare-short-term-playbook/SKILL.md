# A 股短线研判词汇表

短线的技巧**已经沉到信号层**了。能写成判据的东西住在使用者项目根目录下的
`信号层判据规格.md`（下称**规格书**），由确定性代码执行。

**项目需提供的文件**（相对项目根目录）：规格书 `信号层判据规格.md`；`AGENT.md`（项目约定，下文引用其 D2 条）；
`observer/scoreboard.py`（`METRICS` 与 `PHASE_EXPECTATIONS`）；以及项目数据目录里的日线与市场层数据
（`regime_history` 等）。本 skill 只读这些文件，不改。

**留在研判层的只有语言。** 这个 skill 就是那份语言：术语的含义、读数的口径、以及在什么情况下
一个读数会骗你。它不给入场判据，也不复述任何阈值——需要数字时，引用规则 ID 去规格书取。

`AGENT.md` D2 认可研判层只做四件事，**没有一件是选股**。本 skill 供其中三件取词——
解释器（归因）、否决闸门、题材联想；策略进化由 `ashare-strategy-validation` 服务。

## 素材优先级：冲突时按这个裁决

三份素材互相矛盾。书房说「过强易折」，威廉斯说「顺势而为」，宝典 108 招里既有追涨也有抄底。
没有优先级，模型会挑那条支持它当前叙事的——**这是幻觉最常见的入口，它伪装成「博采众长」**。

> **平台数据 > 规格书规则 > 书房（A 股、2025-12、正对低吸/反包） > 宝典 108 招 > 威廉斯（异市场，仅方法论）**

两条素材在同一命题上冲突时，它**变成 `ashare-strategy-validation` 的证伪候选，不是当晚的判断题**。

素材可信度差异有据可查：书房的规则自带阈值、止损与失效条件（`SPEC-SETUP-03` 明写「跌破 D3 阳线最低价即失效」）；
宝典第 2 章 24 个 K 线形态**对「失败/无效/止损/失效」的全文检索命中数为 0**，且第 5 章 25 个实例
后市涨幅中位数 +93%、无一失败样本、时间高度集中在 2018–2020 两段普涨行情。详见规格书 §17。

## 术语表

一个概念一个名字。**括号里是同义词，认得即可，输出时一律用左列的词。**

| 术语 | 含义 | 规则 ID |
|---|---|---|
| **初强** | 底部长期横盘缩量之后，第一次放大量涨停并突破全部短期均线。资金开始攻击的信号 | `SPEC-EXH-02` |
| **末强**（过强易折） | 强势的衰竭阶段：连板已高、换手急剧放大、烂板出现。**强度还在，可持续性没了** | `SPEC-EXH-01` |
| **物极必反** | 用换手率读情绪顶：同样是涨，缩量涨停是惜售，天量涨停是分歧 | `SPEC-VOL-02` `SPEC-VOL-03` |
| **烂板** | 涨停板反复被砸开又封上。伴随极高换手时是末强的确认项 | `SPEC-VOL-04` |
| **锁筹** | 换手极低而价涨。筹码不愿出手 | `SPEC-VOL-02` |
| **分歧** | 换手急剧放大而价滞涨。多空在高位充分交换筹码 | `SPEC-VOL-03` |
| **反包** | 涨停突破前高 → 次日巨量阴线制造恐慌 → 第三日翻红。**本平台的主形态** | `SPEC-SETUP-03` |
| **洗盘 / 出货** | **两者事前不可区分。** 见下方「不可判定项」 | — |
| **生命线** | 30 日均线。书房整套体系的参照物，四态：压制/走平/支撑/破位 | `SPEC-MA-01` |
| **空中加油** | 一浪放量 → 二浪缩量整理 → 三浪更大量突破 | `SPEC-SETUP-05` |
| **龙头 / 后排** | 板块内最强的一只 / 其余跟风股。「后排杂毛」是同义俗称 | `SPEC-LEAD-03` |
| **地量 / 天量** | **书里从未定义。** 见下方「不可判定项」 | — |
| **情绪阶段** | `phase` 六段：冰点/启动/主升/高潮/退潮/修复。**实测修复占 84.8%（评分口径 86.1%），高潮 0 次** | 规格书 §1.2 |

## 三个必须靠语言的判别

规格书能算的都算了。剩下这三件事**算不出来**，所以留在这里。

### 1. 初强 vs 末强

同一只票、同样在涨停，**这个判别决定买还是躲**。数值部分见 `SPEC-EXH-01/02`，
但数值只覆盖一部分——书房原始判据里约有 40% 依赖分时（烂板的盘中形态、分时均价线），平台没有分时数据。

所以这是个**带缺口的判别**：日线能给出倾向，给不出定论。表述时必须说明是哪一档证据支撑的。
详见 `references/初强末强与出货.md`。

### 2. 板块逻辑归因

三步复盘的第 2 步：看到涨停股，回答**「为什么涨、属于哪个板块」**——新政策发布？行业基本面变化？
新技术突破？这一步**不在任何财务表或技术指标里**，规格书 `SPEC-LEAD-02` 明确把它标为研判层的活。

今天没有新闻/公告数据源（缺口 G6），所以归因只能基于已知题材知识 + 板块共振事实。
**没有信息源时的正确输出是「无法归因」，不是编一个政策出来。**

### 3. 题材联想的发散映射

谐音、缩写、概念牵强附会。**这是全系统幻觉面最大的节点**，三条护栏见
`references/龙头板块与题材联想.md`。

## 不可判定项：明确说出来，而不是绕过去

这三样在素材里被大量使用，但**它们没有可判定的定义**。遇到时的正确动作是**说明不可判定**，
而不是挑一个数字假装能判。

**① 洗盘 vs 出货。**（否决闸门的主要取材处，可测的部分是 `SPEC-EXH-03` 放量滞涨与
`SPEC-EXH-06` 真出货。）宝典招 106 原文：「因为在下跌过程中成交量始终表现为缩量，说明庄家是在洗盘而不是出货」——
这句话没有任何证据支撑，且是循环论证。可测的残留只有「缩量回调」这个事实本身（`SPEC-STRUCT-08`）。
**描述观察到的量价，不要描述主力的意图。**

**② 地量 / 天量。** 宝典全章使用数十次，**从未给出基准、回看窗口或倍数**。规格书里凡出现这两个词处，
都已改写为显式表达式（如 `volume = max(volume[-20:])`），并标注该数字是实现者的补充、不是书里的内容。
**引用时引用表达式，不要引用「天量」这个词。**

**③ 艾略特浪的浪型编号。** 浪可以事后重标，构造上不可证伪。已入规格书 §16 墓地。

## 字段语义陷阱

**这一节比术语表更容易救你。** 平台字段的名字会误导，实测如下：

| 字段 | 陷阱 |
|---|---|
| `up_ratio` | 是**涨家数 ÷ 跌家数**，不是上涨占比。实测某日 `0.8127`，同日 `up_count=2322 / down_count=2857`——看着像 81% 上涨，实际只有 44.8% |
| `avg_turnover` | 是**成交额（元）**，不是换手率。个股换手率用 `turnover_rate` |
| 量纲混用 | `seal_rate` `promo_rate` `above_ma20_pct` 是 0–1 小数；`strong_up_pct` `strong_down_pct` 是 0–100 百分数。**同一张表两种量纲** |
| `turnover_rate` | **百分数 0–100**（实测中位 2.12），而同一张日线表的 `change_pct` 是小数。书房的 5–8%/25%/40% 可直接比，**不要再乘 100** |
| `median_pct` | **死指标**：`scoreboard.py` 的 `eps=0.5` 是按百分数写的，落盘值是小数，实测 243/243 天恒为「持平」 |
| `phase` | EMA(α=1/3) + 两日确认的**同步/滞后**标签。**把它当次日预测读，就是记分牌已经抓到的那个陷阱** |

完整台账见 `references/字段语义与缺口台账.md`。

## 引用纪律

写归因或排除理由时：

- **引用规则 ID + 具体字段值**，例如「`SPEC-VOL-03` 命中：`turnover_rate=27.4%`、`consecutive_limit_ups=4`」
- 该规则标 ⚠️ 或 ❌ 时，**说出降级了什么**：「原判据要求分时确认，无 `kline_minute`，以收盘价代理，可信度降一档」
- **无字段可引用时输出「数据不足以判定」**——这是一等结果，不是失败
