# 三步复盘的降级口径

书房的原始三步需要热度榜和涨停池，平台两个都没有。这里是能跑的版本。

## 第 1 步 · 候选池

**原始**：每天扫描热度榜前 50，只看近期有过涨停的股票。
*热度榜代表资金流向，近期涨停说明个股具备爆发基因，二者结合能捕捉到真正的市场热点。*

**缺什么**：热度榜（G5）、涨停池/炸板池（G2）。

**降级**（`SPEC-LEAD-01`）：

```
候选池 = 当日 amount 排名前 50
       ∩ max(consecutive_limit_ups[近 5 日]) >= 1
```

**降级损失（要说出来）**：成交额排名 ≠ 人气排名。成交额偏向大市值，
而超短线的热点常在中小市值——**这个代理系统性地漏掉一部分真热点**。
`mainline_history` 的概念/行业主线 top-30 可作为补充维度，但它同样有前视问题（见第 2 步）。

## 第 2 步 · 追问逻辑

**原始**：看到涨停股，务必探究上涨背后的逻辑——是源于新政策的发布？行业基本面的变化？
还是新技术的突破？明确逻辑后标注在自选股中。

**缺什么**：新闻/公告/研报（G6）；龙虎榜的 `limit_reason` 字段实测不返回。

**能做的**：模型自身的题材先验 + 板块共振事实（同概念多只同时异动）。

**不能做的**：编造一条政策。这是本节点最典型的失败方式——它读起来完全合理，
而且**没有任何字段能证伪它**。

写法与证据分级见 `归因写法.md`。

### 「板块」怎么选：一只票挂着十几到四十几个概念

同花顺概念表里一只票常挂 17–43 个概念（实测 600869.SH 挂 43 个）。**必须有选取规则，否则每次结论都不同。**

按顺序取第一个命中的：

1. **能解释同池共振的那个概念** —— 候选池里多只票共有、且当日该概念整体表现显著偏离全市场中位
2. **当日在 `mainline_history` concept 榜排名最高的那个**
3. 以上都没有 → 用 THS 行业分类（`ext_hy_ths`）消歧
4. 还是没有 → `sector: 无法归类`，并在 `attribution_level` 写 `无法归因`

**输出时写清用了哪一条。** 概念是当前快照（无历史版本），所以这个选取本身也带前视污染。

## 第 3 步 · 龙头确认，砍掉后排

**原始**：当市场选出真龙后，果断聚焦核心，后排杂毛一律砍掉。

**缺什么**：封板时间、封单量（G3）——这才是行业口径的龙头判据。

**降级**（`SPEC-LEAD-03`）：板块内按 `consecutive_limit_ups` 降序，并列按 `amount` 降序，
第 1 名为龙头。

**⚠️ 前视污染**：同花顺概念/行业成分表**只有当前快照，没有历史版本**。
「这只票属于 X 板块」这句话在历史回看里不可信。任何基于板块的历史结论标 `不可回测`。

**⚠️ 一条待检验的风格漂移**：书房（2025-12）明确称连板为王已成为量化的收割对象，
换手/多波/反包优于单纯连板。**如果这是真的，用 `consecutive_limit_ups` 排龙头这个降级口径
本身就是错的。** 已登记为候选假设 H1，在回测出结论之前，龙头判定要带这个保留意见。

## 三步跑完的完成判据

候选池里每一只都有 **`sector`、`attribution_level`、`role`** 三项（与 SKILL.md 的输出契约一致）。

**一只都不能空着。** 空着说明这一步没跑完，不是「暂时不确定」。
`sector` 可以是 `无法归类`、`attribution_level` 可以是 `无法归因`——**填上「不知道」是合格的，留空不是。**
