# 作文诊断与批改（按评分标准四维度）

## 评分口径：从官方标准入手，Joe 体系给建议

- **批改从四个维度的官方描述符入手**（[band-descriptors-task2.md](band-descriptors-task2.md)）：逐维度对照标准，每项挑 2-3 个**真实存在**的典型问题给诊断建议——该维度没问题就不写，**不硬凑**
- **提分路径 = 相邻两档描述语的差异**（官方本身有定论，**适用于任何分数段**——学生作文可能在任何一档）：先定档，再把当前档和上一档的原文摆出来对比，差异就是提升目标。例：TR Band 6 "main ideas inadequately developed/unclear" → Band 7 "presents, extends and supports main ideas"
- **Joe 的方法是这些官方差异的操作化**：提到相关标准条目时，把对应方法作为建议带出——如"发展不充分"→ 具象化/因果链（body-paragraph.md）；冲 7 语言 → language-upgrade.md（名词化 + Hedging + 引用动词 + 口语词替换）
- 两者冲突时以官方为准

**大作文分数段地图（Joe 对官方 6/7 档差异的操作化）**：主体教学体系（审题/论证/具象化）解决到 **6-6.5**；冲 **7+** 走 [language-upgrade.md](language-upgrade.md)

## 批改框架：四个维度逐个点评

雅思大作文评分四维度，每个维度挑 **2-3 个最典型的问题**指出，不求全责备：

| 维度 | 缩写 | 看什么 | 权重感知 |
|------|------|--------|---------|
| Task Response | TR | 审题、立场、论证质量 | 内容观点 |
| Coherence and Cohesion | CC | 结构、分段、衔接 | 逻辑结构 |
| Lexical Resource | LR | 词汇 | 语言表达 |
| Grammatical Range and Accuracy | GRA | 语法 | 语言表达 |

**认知锚点**：TA/CC（内容+逻辑）和 LR/GRA（语言）各占 50%，但"想 ideas、组织论证"这部分是纯汉语思维，跟英语无关——英语基础弱但内容逻辑好的学生，写作照样能高。

## TR（Task Response）诊断顺序——按杀伤力从大到小

前面的问题不解决，后面的不用谈。

### 1. 审题（跑题 = 最高 5.5）

- 题型识别对吗？结构跟题型匹配吗？（Discuss 写一边倒 = 结构错）
- 每个主体段的论述对象对题目吗？
- 回应的是题目问的那个观点吗？（麦当劳 vs 汉堡王问题）
- （绝对词题）碰绝对词了吗？

### 2. 论证（观点堆砌 = 最高 5.5）

- 每个观点后面有"为什么"吗？
- 是观点列举（第一第二第三）还是论证展开？
- 因果链完整吗？有没有跳步？

### 3. 论据真实性

- 论据在现实中存在吗？（"监狱不够坐就放人"类一票否决）
- 写的是考官能理解的相通经验吗（非中国特色）？

### 4. 具象化（Band 6 → 7 的分水岭）

- 抽象概念有没有下定义/举例子？
- 有没有"假大空"表达（"促进发展""提高质量"——什么发展？怎么提高？）

### 分数锚点（TR 视角）

| 表现 | 分数段 |
|------|--------|
| 跑题 / 只提观点 / 假大空 | ≤5.5 |
| 有论证但不清楚（unclear） | 6-6.5 |
| 论证完整清楚（clear + developed） | 7+ |

## CC（Coherence and Cohesion）看什么

- 分段是否服务结构（每段一个清晰的 central topic）
- 衔接词是否恰当（under-use / over-use / mechanical 都是 Band 6 特征）
- 指代是否清晰

## LR（Lexical Resource）看什么

- 词汇够不够用（能否准确表达意思）
- 搭配是否地道
- 大作文语言目标：**让人看懂即可**，不追求华丽

## GRA（Grammatical Range and Accuracy）看什么

- 最低标准："They do not impede communication"——可以有错，但不能让考官看不懂
- 句子写不对的学生 → 转 [grammar-foundations.md](grammar-foundations.md) 主干法补课，先补语法再练写作
- 复杂句的使用是否有控制地多样（三类从句、分词、不定式修饰）

## 反馈原则（Joe 的方式）

1. **按四维度逐个点评，每个维度挑 2-3 个真实存在的典型问题**——不流水账式全改；该维度没问题就不写，不硬凑
2. **TR 问题永远最先讲**——跑题/无论证不解决，词汇语法改了也没用
3. **先给选项再给答案**——能让学生自己发现问题就不直接指出
4. **用对比展示**——学生句子 vs 修改后句子并排，让他看到差别
5. **肯定进步**——改对了简短肯定（"对，这次论述对象对了"），再进下一个维度

## 考试 40 分钟时间分配（供学生参考）

```
审题 2-3 分钟：读两遍 → 定类型 → "为什么"转述定方向
Brainstorming 5-7 分钟：具象化/情景化 → 定每个论点
写作 25-30 分钟：开头 → 主体段(80-120词/段) → 结尾
检查 2-3 分钟：跑题？论证？事实？拼写语法
```
