# Task 1 流程图与地图题（Diagram）

> 数据图之外的两种题型。考试频率：数据图（最常考）> 地图题 > 流程图。
> **例题原图 + Band 9 范文（老师上课用）**：`../assets/task1-diagrams/`——map-chorleywood-village（村庄发展）、map-gallery-proposal（画廊改造）、map-climate-houses（寒暖气候建筑）、map-garlsdon-supermarket（超市选址）、process-weather-forecast（气象预报流程）。每页含题图+范文，讲解时直接引用。
> 参考来源：writing-task-1-band-9-collection.pdf（Simon T1 范文精选）。

## 〇、与数据图的根本区别

流程图**没有数字**——不能比较任何东西、不能描述趋势。能写的只有：
1. 流程共**多少步**
2. 流程**从哪里开始、在哪里结束**
3. **每一步**发生什么

## 一、流程图（Process / Flow Chart）

### 两类形态
- **人造流程**（线性）：如玻璃怎么造、某种食品怎么生产（Step 1 → 2 → … → 6）
- **自然循环**（环形）：如水循环、蝴蝶生命周期（循环无终点）

### 段落结构（同数据图骨架）
Introduction（1 句）→ Overview（stages 概括）→ Details 1 → Details 2

### 时态与语态
- 客观流程 → **一般现在时**
- **多用被动语态**：材料被处理（A is heated），而不是机器主动处理材料

### 模板

**Introduction**：The given flow chart illustrates the process of ___.

**Overview**：Overall, the whole procedure comprises ___ distinguishing stages.

**顺序连接词**（比数据图更重要，这是 CC 的全部来源）：
- Firstly / secondly / thirdly / finally
- The first step is to... / The first stage involves...
- In the next stage / in the following stage / in the last stage
- First of all / to begin with / next / then / later
- At the same time / simultaneously / subsequently / consequently
- Before this / during / after this / in the course of / in order to / so as to

**流程动词库**（图中词汇直接用，不替换复杂专业词）：
produce 生产；lay 放置；accumulate 积累；gather/collect 收集；obtain 获得；heat up 加热；expand 膨胀；bend 弯曲；disconnect 断开；spin 旋转；compress 压缩；release 释放；accelerate 加速；form 形成；process 加工；press 按压；rotate 旋转；chop 砍；grind 磨；burn 燃烧；fold/unfold 折叠/打开；transform 完全改变；dissolve 溶解；recycle 回收；extract 提取；convey 运送；melt 熔化；evaporate 蒸发；shrink 收缩；replace 取代

## 二、地图题（Map / Comparison Diagram）

### 题型本质
对比图：描述**变化**（旧设计 vs 新设计、两个备选方案、两个选址）。

你的任务四条：Describe the changes / things that don't change / the differences / the similarities.

### 时态
- 单图 → 一般现在时
- 多图对比：**第一张图多用过去式**（变化前的样子），第二张可用现在/将来

### 模板与语料

**Introduction**：The given map illustrates the transition of the landscape in (place) between (year) and (year).

**Overview 两句**（与数据图不同，写这两点）：
1. **功能改变**（这块地/建筑从什么变成了什么）
2. **新增/消失的东西**（什么被建了、什么被拆了）

**Details 顺序**：先写最明显的变化，再写四周；顺时针或从左到右（空间顺序统一，别乱跳）

**方位表达**：
- Clearly, ..., surrounded by ..., can be divided into ... main regions.
- There be / we can see / lie / be located / be situated / can be found
- In the east/west/south/north of...; in the southwestern corner of...; at the southern end of the river
- alongside / opposite / bordering / next to
- A main road/river runs through ... from ... to ...

**变化动词**（地图题的"趋势词"）：
- 数量：more / less / fewer; increase / decrease
- 大小：enlarge / become smaller
- 建造：build / establish / construct / set up / erect → newly built...
- 替换：replace / give way to / transfer → former...
- 记住 be 动词变化：was expanded, was added, was relocated, was replaced by

## 三、教学提醒（源自课堂实录的补充要点）

**流程图：**
- 学生最怕"没有数字"，先安抚：考的频次非常低、本身过于简单，套路比数据图还固定
- **不认识词没关系，看图就行**：学生把砖工艺图猜成"做巧克力/刀片电池"——教他们"什么时候用得到挖掘机？"式读图
- 客观报告的示范："挖掘机本身不会挖粘土"→主语换成粘土，被动：Clay is dug out from the ground
- 只用图上给的词大致描述；开放型流程 vs 循环型（自然循环常有编号，按编号说）
- 范文连接词值得学：at the beginning of the process（比 firstly 充实字数）

**地图题：**
- **核心就两个：方位报告 + 变化/差异**；不要写上下左右，写东南西北
- 经典纠错："村不是移动的城堡"——是向南**扩张**（expanded to the south alongside the main road），不是 village moved
- 区域型（随时间发展）：按时间区间分段（如 1968-83 / 83-22 / 22-70 / 70-94），先以标题主体（村）为主说方位
- 户型图（现状 vs 规划）：行文顺序按**第一张图的走序**（从入口往里走），分段按变化数量（4 个变化两两一对）
- 介质结构（如寒冷 vs 温暖气候建筑）：无时间变化，按差异内容分段，直接抄图上词（insulation / reflective material）改词性即可
- 学生把 motorway/railway 当独立元素分段的错误要纠正：先看时间区间，它们不是一开始都有的

## 四、通用提醒

- 学生最怕这两种题（没数字没数据），先安抚：题型少、套路固定，掌握模板比数据图还省心
- 流程图第一课就是**接受"没有数字"**：把"报数据"的肌肉记忆关掉，换成"报步骤"
- 地图题第一课是**时态判断**：先看是一幅图还是两幅图
- Overview 在地图题里写"功能改变+增删"，流程题里写"阶段数"——都不是数据图的 trend/difference
